# 总公司核保意见生成规范（台账语料提炼）

> **语料基线**：团险核保台账（1120LC）"询价台账"sheet，872 条意见 / 240,571 字符，覆盖 2024-07-02～2025-11-17。结论分布：**零拒保、零延期**，全部为"条件承保（拟同意＋风控条款）"或"建议谨慎承保"（115 次）——总公司意见的职能是**定价纠偏与风险条件化**，不是否决。
>
> **话术版本演化**（生成时按当前时点取最新版）：2024上半年"拟同意分公司核保意见/以签报内容为准"→ 2024下半年起统一"运营初审意见＋以签报为准"→ 2025下半年起新增"重大既往症范围"标准附文。当前（2025-11+）默认用最新版。

## 1. 意见标准结构（五段式）

```
1、[健康告知条款——几乎每单必有]
[重大既往症范围全文——2025-11起新单标配，紧随健康告知条款]
2、[既往赔付数据处理条款——基于理赔数据的核心条款，含具体数字]
3、[风险因子条款——触发即加，0~n条]
4、[操作合规条款——意外险录系统等]
综上，其他部分拟同意分公司运营初审意见，请团险部审批，最终意见以签报为准。
```

编号连续、条款末尾用分号、结论句独立成行。条款顺序：健康告知 → 赔付数据 → 风险因子 → 操作合规。

## 2. 条款触发规则矩阵

### 2.1 健康告知条款（规则矩阵：业务类型 × 年龄 × 险种）

| 条件 | 条款变体 |
|---|---|
| 新单/转保 | `需提供团体健康告知书，明确被保人重大既往症情况并进行除外，若有异常须及时报送总公司审核` |
| 续保 | `若有新增被保人或未连续投保被保人，需提供团体健康告知书，明确被保人重大既往症情况并进行除外，若有异常须及时报送总公司审核` |
| 被保人超50岁 | 追加：`其中新增被保人或未连续投保被保人年龄超过50周岁的，须提供个人健康告知` |
| 含重疾险且≥50岁 | 追加：`投保重疾且年龄超过50周岁的须提供个人健康声明` |
| 人数极少的短期新单 | 变体：`所有被保人均提供团险被保险人告知声明书，若有异常，审核通过后方可承保；若当前提供困难可先进行问询，若有异常告知请提前沟通` |
| 自保件 | `建议新增被保人超过50周岁的提供个人健康声明` ＋ `请分公司确认方案及保费设置符合人力要求后再上报OA` |

**重大既往症范围全文**（2025-11 起紧随健康告知条款附上，逐字不可改写，见附录A）。

### 2.2 既往赔付数据处理链（核心决策条款）

**判定链**：调取分年度综合赔付率（注意理赔滞后，未到期年度"暂未发生赔付"如实写）→ 与"保费扣除综合费用率后余额"比较 → 四分支：

| 分支 | 判定 | 话术与动作 |
|---|---|---|
| ① 可覆盖 | 赔付率显著低于保费-费用率余额 | `截止X年X月X日既往赔付率X%，基于既往方案、被保人、特约等均与本次询价内容基本一致，保费扣除综合费用率后可以覆盖预估赔付` → 拟同意报价 |
| ② 有风险 | 持平或轻度超赔 | 手段按优先级选用：`建议保费上浮至X元每人`（高频195次）／`建议X险种按标准保费收取`／`建议门急诊调整为X元免赔额、X%赔付比例，住院医疗调整为X%赔付比例`／`剩余保费分摊至X险种中`（避免同类产品折扣差异过大）／`建议方案中补充医疗保险按X元每人收取` |
| ③ 严重超赔 | >100% | 多手段叠加 ＋ `被保人极少，无法有效分摊风险，故建议谨慎承保` |
| ④ 无数据 | 新单/转保/资料缺失 | `新单业务无既往赔付数据参考，存在超赔风险，建议谨慎承保，请业务部门结合全渠道业务情况进行审批`；转保可补充：`本单虽已通过增加免赔额、调整赔付比例等风控措施进行赔付风险防范，但因无社保、无既往数据，仍建议谨慎承保` |

**数据叙述标准模板**（数字逐项写明，不留空）：
`续保业务，既往超赔，上一年度投保在我司，总保费X元，截止X月X日理赔金额为X元，综合赔付率为X%，本年度加费投保，X险种预估赔付X元每人，基于此，建议……`

**转保数据叙述模板**：`根据分公司反馈，上年度投保X公司，本次投保方案不变/变化为……，投保人数由去年X人增至X人，平均年龄由X岁降至X岁，预估完整赔付率约X%-X%，基于此，……`

**分险种赔付率叙述模板**：`既往X年门诊赔付金额X万元，住院赔付金额X万元，其中在职员工X责任赔付率X%、连带子女X责任赔付率X%，需计算上调续保年度对应费率`

### 2.3 风险因子条款（触发即加）

| 因子 | 条款话术 |
|---|---|
| 人数过少/保险期间短 | `因被保人数过少，且保险期间X，无法有效分摊风险，不建议免除重疾等待期` |
| 无社保 | `无社保被保人出险时按照保险计划中赔付比例等要素和条款要求执行`；且费率与责任联动建议（免赔/比例上调） |
| 高空作业/职业风险 | `请分公司核实被保险人工作内容及环境，确保职业类别无误，若有超出询价方案中职业类别的职业风险，须重新报送总公司审批`＋`被保险人因从事在坠落高度基准面2米以上（含2米）的高空作业导致的意外事故为除外责任` |
| 劳务派遣/人力资源 | `请分公司重点核实被保人与投保单位是否存在投保利益（与投保单位签订劳动合同），确保存在投保利益后方可投保`；`针对退休人员，请确保投保单位对其存在保险利益` |
| 主体变换 | 同上投保利益核实 |
| 高龄+意外险为主 | `考虑被保人平均年龄X且无社保，发生意外风险较高，且意外医疗、住院津贴、护理保险预期保费极低，存在赔付风险，建议谨慎承保` |
| 高保额意外/交通 | `被保人年收入不得低于X万元，请分公司核实被保人收入符合要求后再上报OA，若交通工具意外伤害保险发生理赔需提供被保人年收入不低于X万元的收入证明`（10万保额档/30万保额档） |
| 连带被保人 | 连带子女方案费率/责任不得高于主被保人；生育险：`建议特约女性生育医疗费用补偿需首先经由社保报销后剩余未报销金额再向我司索赔` |
| 未成年 | `增加未成年被保人身故限额相关特约话术`（不满10周岁≤20万、10-18周岁≤50万） |
| 意外险（操作） | `意外险保单需在保险起期前将承保信息及时准确录入核心业务系统` |
| 追溯生效 | `若涉及追溯生效日的，请对追溯原因及追溯期间理赔情况进行详细说明`（防"先出险后加人"逆选择） |
| 特约违规 | `特约中不可对团体补充医疗保险进行赔付限额，请删除此条特约` |

### 2.4 系统性硬约束（定价合规底线）

- 福安团意险费率浮动不得低于标费25%；半年期标费=一年期×0.7
- 突破费率表/条款规定的，须记录备报产品精算部审批
- 手续费上限按渠道谈定（语料出现过6%/8%/10%/20%各档），写入意见：`整单手续费以X%为上限`
- 高收低折调整：`考虑定价合理性，建议意外医疗按标准保费收取保费，剩余保费分摊至福安意外伤害保险中，避免出现同为意外险类产品，费率折扣差别较大的情况`
- 高收下限话术（总部反馈常用）：`方案一以X元为下限，高收保费全部放入门诊责任`

## 4. 生成流程（输入 → 输出）

1. **输入识别**：询价单（doc，含客户结构/方案/标准保费/预期保费/特别约定/既往赔付史）＋既往核保理赔数据（询价单内嵌或台账/理赔表，均可）。
2. **数据提取**：业务类型（新单/续保/转保/自保件）、人员结构（人数/年龄/性别/社保/连带）、险种组合与保额、分年度保费/赔款/赔付率（标注理赔成熟度）、分公司初审意见要点、职业类别。
3. **规则引擎**：逐条过 §2 触发矩阵 → 生成条款清单（健康告知→赔付数据→风险因子→操作合规）；赔付数据条款必须含具体数字，无数据的写"无既往赔付数据参考"分支。
4. **组装**：按 §1 五段结构编号组装；结论句按 §3 选择。
5. **质检**：对照 §5"分公司请关注"十条自检（询价前后一致性、职业按实际工作内容、连带不高于主被保人等）。
6. **输出**：意见全文（可直接抄录询价单"总公司核保审核意见"栏），落款核保人+日期。

**与量化评估的关系**：已跑 gi-renewal-underwriting-eval 的多情形测算时，赔付数据条款中的调整建议（比例/免赔/上浮幅度）直接引用测算结论，且遵守"联动调价抵消"洞察——比例下调建议须同时写明报价维持不降。未跑量化测算时，按 §2.2 判定链直接从赔付率分支。

## 5. 质检清单（"分公司请关注"十条，语料原意）

1. 标准保费各要素对应（保额/免赔/比例/职业/年龄结构均取对）；2. 职业类别按实际工作内容而非经营范围判定；3. 询价前后方案要素一致；4. 突破条款费率的记录备报；5. 紧急业务合规优先；6. 追溯业务防"先出险后加人"；7. 意外险录单早于生效时间；8. 既往理赔需核对人员/方案/保额/特约与本次一致性；9. 高保额提前告知；10. 连带被保人不高于主被保人。

## 7. 实战范例（语料代表性意见，生成时对照风格）

**例1 续保可覆盖**：`1、健康告知若有异常须及时报送总公司审核；2、截止2024年6月3日既往赔付率23.5%，基于既往方案、被保人、特约等均与本次询价内容基本一致，保费扣除综合费用率后可以覆盖预估赔付。综上，拟同意分公司核保意见，最终意见以签报内容为准。`

**例2 超赔调整**：`1、新增被保人或未连续投保被保人需提供团体健康告知书，其中超过50岁的被保人须提供个人健康告知，明确被保人重大既往症情况并进行除外，若有异常须及时报送总公司审核；2、续保业务，既往超赔，上一年度投保在我司，总保费33585元，截止1/3理赔金额为56215.51元，综合赔付率为167%，本年度加费投保，补充医疗预估赔付3940元每人，基于此，建议所有方案中门急诊、住院赔付比例均调整为50%，方案二门急诊按标准保费收取；被保人极少，无法有效分摊风险，故建议谨慎承保。综上，其他部分拟同意分公司运营初审意见，请团险部审批，最终意见以签报为准。`

**例3 新单无数据**：`1、健康告知若有异常须及时报送总公司审核；2、门急诊、住院医疗保费较低，新单业务无既往赔付数据参考，存在超赔风险，建议谨慎承保，请业务部门结合全渠道业务情况进行审批。其他部分拟同意分公司核保意见，最终意见以签报内容为准。`

**例4 高空职业**：`1、请分公司核实被保险人工作内容及环境，确保职业类别无误，若有超出询价方案中职业类别的职业风险，须重新报送总公司审批。2、被保险人因从事在坠落高度基准面2米以上（含2米）的高空作业导致的意外事故为除外责任。综上，其他部分拟同意分公司运营初审意见，请团险部审批，最终意见以签报为准。`

## 附录A：重大既往症范围（全文，逐字使用）

`重大既往症范围：中国保险行业协会下发的《重大疾病保险的疾病定义使用规范（2020年修订版）》中定义的 28种重度疾病、3种轻度疾病，以及恶性肿瘤、原位癌、心脏病（心功能不全Ⅱ级以上（不含Ⅱ级））、心肌梗塞、白血病、高血压病（Ⅱ级以上（不含Ⅱ级））、肝硬化、慢性阻塞性支气管疾病、脑血管疾病、慢性肾脏疾病、胰岛素依赖型糖尿病、再生障碍性贫血、先天性疾病、精神疾病、癫痫病、法定传染病、艾滋病、性病、肺结节、甲状腺结节有以下症状中的任意一项、乳腺结节有以下症状中的任意一项及正患病住院全休、半休者：1）甲状腺结节：① 甲状腺分级彩超TI-RADS 3级及以上；② 单边大小超过1CM及以上；③ 边界不清晰；④ 结节内部或周边有血流（毛刺、分支等）；⑤ 内部有钙化点（点状强回声、彗星扫尾等）；⑥ 颈部可见淋巴结节；⑦ 结节大小纵横比超过1。2）乳腺结节：① 乳腺分级彩超BI-RADS 3级及以上；② 单边大小超过1CM及以上；③ 边界不清晰；④ 结节内部或周边有血流；⑤ 内部有钙化点；⑥ 腋窝下淋巴结肿大。`
