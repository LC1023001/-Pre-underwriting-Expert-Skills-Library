# 报价引擎规范（源自《企业团体保险自动核保报价单_v1.2》工作簿）

> **本文件在技能中的用法**：本文件是"团险核保报价单意见生成"技能的定价引擎规范，提供备案费率表全集、查表公式链、人数加权规则、赔付判断三色判定与校准警示。工作流第3步"报价测算"严格按本文件执行；测算结论回流第5步"组装意见"，作为赔付数据条款中的量化纠偏依据。核心铁律见文首【定价五铁律】。

## 0. 定价五铁律（执行纪律，违反即返工）

1. **人数加权，禁止简单平均**：多年龄档/在职退休混合结构的标准保费必须按各组人数加权汇总。禁止把两档单价做50/50算术平均（教训：某宾馆案询价单把在职档1469.80与退休档3827.36简单平均得2648.58元/人，而实际退休占比66.25%，人数加权应为3031.68元/人，低估383.10元/人/14.46%）。
2. **分组定价**：一个方案含多群体（如在职/退休/实习生）时逐组查表计算，再按人数汇总；工作簿单表只支持一个在职档+一个退休档，超出即拆组。
3. **系数表不混用**：住院三项（基本医保金/小额医疗/大额医疗）共用一套赔付比例系数（80%基准1.00，90%→1.15，100%→1.35）；小额门诊是在职0.80/退休0.85（90%档）；大额门急诊直接按（年龄档×赔付比例）查价不乘系数。三套规则互不通用。
4. **未覆盖险种不虚构**：吉祥行交通工具意外、福安团意费率下限（不低于标费25%）、半年期×0.7等本引擎未含的险种/规则，费率沿用询价单或同业报价原文，意见中标注来源，不得虚构。
5. **先校准再判定**：人均赔付成本1,688元/人/年为v1.0沿用"待校准"参数（对应六项全保全人群口径）。缩减保障方案（如仅住院三项）须按保障结构折算成本（备案价比例折算法）或强制录入实赔数据后才能采信三色判定，否则产生假红牌/假绿牌。

### 2.4 判定规则与分支条件汇总
1. **险种开关**：A列选(1/0)直接乘进保费公式——不买的险种单价仍计算但不进总价。
2. **口径分支**：E列="‰"→保费=人数×保额×费率÷1000×系数；"元/人"→保费=人数×单价×系数。
3. **住院三项**（基本医保金/小额医疗/大额医疗）共用赔付比例调整系数表：80%为基准1.00；90%→1.15；100%→1.35（非线性，比例越高边际加价越小）。
4. **超大额医疗**：六项中唯一无年龄轴，只按赔付比例取价（80%→35，90%→42，100%→61元/人）。
5. **小额门急诊**：先按（年龄档×免赔额）查备案价，再乘门诊赔付比例系数（在职与退休两套系数，与住院三项的系数表完全不同，不能混用）。
6. **大额门急诊**：直接按（年龄档×赔付比例）查价（列序100%→50%），不乘任何系数。
7. **意外身故**：基准1.5‰（1类）×职业备案因子（1类1 / 2类1.32 / 3类1.75 / 4类3）。
8. **意外医疗**：线性公式 19+MAX(0,(保额−2000)/1000)×1.62（有社保价）×职业因子（1/1.25/1.5/2.25）；无社保客户需×24/19（已知限制，公式未内建社保开关）。
9. **女性生育**：全员单价 = 2×女性占比×[Beta×有社保表＋(1−Beta)×无社保表]×赔付比例。
10. **偏离系数**：新单恒为1；续保 = 上年赔付率÷0.804（80.4%＝1,688÷2,100沿用口径）。>1表示客户比平均差。
11. **保本线**：保本赔付率 = 1−费用率 = 80.7%。调整后赔付率（商务折后口径）决定出单三色判定：**≤80% 通过（绿，可直接出单）；80%~90% 需审批（黄，需上级审批并说明理由）；>90% 不建议（红，除非客户接受加价或缩减责任）**。
12. **商务调整只折补充医疗**，附加险不打折。
13. **月缴**：按备案附注 ×0.095。
14. **四档加权**（贯穿全表）：加权单价 = (1−退休占比)×[(1−女性占比)×在职男＋女性占比×在职女] ＋ 退休占比×[(1−女性占比)×退休男＋女性占比×退休女]；重疾/住院津贴/团体护理三项的退休人员按在职档计价（偏低，已知限制）。

可直接复用的工作簿资产：①补充医疗六项完整备案费率体系（年龄档×性别×在职/退休×免赔额×赔付比例，含住院三项比例系数表、门诊两套比例系数表、超大额比例表）；②意外身故/意外医疗/重疾/津贴/护理/生育费率与职业因子；③四档加权定价公式链（02页查表→01页单价→保费=人数×基数×单价×系数×开关）；④赔付判断公式链（偏离系数→预期赔付→赔付率→保本价→建议报价→调整后赔付率→三色判定）；⑤费用率构成与80.7%保本线。

合并时必须补的缺口：
1. **吉祥行交通工具意外不在本工作簿**（飞机/火车/轮船50万、营运/自驾汽车30万的费率与79.65元/人的计算逻辑）——只能由另一套询价逻辑供给，合并技能中应作为独立险种模块接入。
2. **单人口结构限制**：工作簿每单只有一个在职档＋一个退休档＋女性/退休占比。本案三群体（在职/退休/实习生）只能拆方案分别试算；同一方案内多年龄段无法分层。合并技能应支持**分组定价：逐组查表加权后按人数汇总**。
3. **修正询价单的50/50加权缺陷**：合并技能的补充医疗计价必须坚持人数加权（本案加权后应为3,031.68而非2,648.58元/人）。
4. 工作簿已知限制应作为核保意见中的风险提示自动输出：重疾/津贴/护理退休按在职档计价（低估）、补充医疗无职业因子、退休档81-85封顶、意外医疗无社保×24/19、备案费率未标注基准保额按1:1处理。
5. **1,688元人均赔付成本为待校准参数**：合并技能对缩减保障方案（如本案方案二仅住院三项）应按保障结构折算成本或强制要求录入实赔数据，否则出单判定会出现口径错配的假红牌/假绿牌。
6. 月缴×0.095、极短期收费比例（意外身故7天8%~12个月100%）、偏离系数（续保=上年赔付率÷0.804）等附注规则应一并纳入技能。

## 摘要
- 工作簿4张表：01_报价单（输入→明细→赔付判断→判定）、02_费率表A（补充医疗六项+查表加权）、03_费率表B（意外/重疾/津贴/护理/生育）、04_说明（口径+已知限制）；无隐藏表、无条件格式，判定逻辑全在公式里。
- 逻辑核心：单价=备案费率表INDEX/MATCH查表（在职/退休×男/女四档）×赔付比例系数（住院三项80%基准：90%→1.15；门诊在职90%→0.8/退休→0.85；大额门诊直接查价）→四档按人数结构加权→保费=人数×单价×开关；赔付判断：预期赔付=人数×1,688×偏离系数（续保=上年赔付率÷0.804），赔付率>80.7%保本线即亏，调整后赔付率≤80%绿/80-90%黄/>90%红。
- 试算结果：方案一（80人，在职41-45档27人+退休66-70档53人，女25%，90%赔付/200免赔，五项责任）工作簿口径**3,031.68元/人**，询价单2,648.58元/人被低估383.10元/人（询价单用了在职/退休50/50简单平均而非66.25%人数加权，已精确到分验证）；方案二（25人，31-35档，仅住院三项）**138.00元/人与询价单完全一致**；交通工具意外（79.65元/人）不在本工作簿，需另一套逻辑；询价预期总保费252,500≈工作簿标准总价254,348（差0.7%，但对消巧合：方案一低1.05万/方案二高0.66万/交通工具高0.21万）。

## 8. 报价测算结论在核保意见中的落地规则（与 opinion-writing.md 的联动）

报价测算完成后，第5步组装意见时按以下规则把量化结论写进第2条"既往赔付数据处理条款"（或新单无数据时的定价纠偏条款）：

1. **报价构成核验句式（新单/转保必写）**：
   `经按备案费率表测算，方案X补充医疗标准保费X元/人（X档住院三项X元×90%赔付比例系数1.15等构成）与费率口径一致/存在偏差……`
   - 一致：直接写"与费率口径一致，予以确认"；
   - 偏差：写明差异根因（加权口径/责任构成/费率档次），给出加权口径正确值。

2. **加权纠偏句式（测出简单平均缺陷时）**：
   `方案X标准保费X元/人系X档X元/人与X档X元/人的简单算术平均，未按人员结构加权，按在职X人/退休X人（退休占比X%）人数加权，标准保费应为X元/人，低估X元/人（合计约X万元），预期保费X元/人仅相当于加权标准保费的X%；基于此，建议方案X补充医疗费率按人数加权口径X元/人为基础重新厘定报价`
   - 数字全部来自测算过程，逐项写明，不留空。

3. **赔付判断三色结论句式**（先完成成本校准）：
   - 绿（调整后赔付率≤80%）：`经测算赔付率X%，低于保本线80.7%，保费可以覆盖预估赔付`（对齐 opinion-writing.md §2.2 分支①话术）；
   - 黄（80%~90%）：对齐分支②，从"保费上浮至X元每人/标准保费收取/免赔额与赔付比例调整"手段按优先级选用，并写明测算依据；
   - 红（>90%）：对齐分支③多手段叠加＋`建议谨慎承保`；若红牌系成本口径错配产生（缩减保障方案未折算成本），如实写明：`赔付判断口径下为不建议（红牌），因人均赔付成本参数待校准，须以X实赔数据校准后再下结论`。

4. **责任构成出入提示**：测算复现发现询价单文字描述与报价构成不符时（如该案方案一文字只写"小额门诊+住院"但价格只在含大额门急诊五项下才能复现），写入：`询价单方案X责任描述与报价构成存在出入，请业务部门确认是否实际含X责任`。

5. **对消巧合警示**：各方案偏差方向相反、总额相近时，写明各方案分项偏差，禁止用"总额基本一致"掩盖分项纠偏需求。

6. **本引擎已知限制→意见风险提示条款自动输出**：含退休人员且投保重疾/住院津贴/团体护理时提示"退休人员按在职档计价偏低"；无社保被保人提示意外医疗×24/19与费率责任联动；退休占比高的补充医疗单提示"无职业因子，职业风险须另行核实"。

## 9. 报价测算标准流程（技能工作流第3步细化）

输入：询价单人员结构（分组人数/年龄/性别占比/社保/职业）＋方案责任参数（各险种保额/免赔额/赔付比例/选投开关）＋报价参数（赔付率口径/费用率/毛利目标/商务调整）。

步骤：
1. **分组**：按群体（在职/退休/实习生/连带等）拆组，每组确定：年龄档（在职按41-45等8档/退休按66-70等8档，超81-85按最高档）、女性占比、人数。
2. **逐组查表**：按所选责任查 §3.2 备案费率表（四档单价×比例系数），得各组人均标准保费。方案内单档结构直接得加权单价；多档结构按"四档加权公式"（§3.1）或逐组人数加权（铁律1）。
3. **汇总**：方案标准保费总额 = Σ各组人均×组人数；人均 = 总额/总人数。
4. **附加险**（意外身故/意外医疗/重疾/津贴/护理/生育）：按 §4 费率与职业因子计算，重疾/津贴/护理退休按在职档（已知限制），生育按表一/表二Beta加权公式。
5. **比对询价单**：标准价差异→定位根因（复现法：尝试用询价数字反推构成——简单平均/漏项/档错）；预期价 vs 加权标准价→实际加费/折价幅度。
6. **赔付判断**：校准人均成本（全保结构用1,688默认并标注待校准；缩减结构按备案价比例折算或要求数据）→ 偏离系数（新单1/续保上年赔付率÷0.804）→ 预期赔付→赔付率→保本价→建议报价→三色判定。
7. **输出测算表**：分组明细＋方案汇总＋与询价对比表＋三色判定＋校准警示，作为意见第2条的数据底稿。
