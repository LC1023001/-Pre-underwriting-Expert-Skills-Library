# 团险核保报价单意见生成（报价测算＋核保意见一体，总公司审核意见）

> **版本记录**：v1.0（2026-11-19）意见规则引擎，基于台账1120LC 872条语料；v2.0（2026-11-19）融合《企业团体保险自动核保报价单_v1.2》报价引擎，新增报价测算步骤与定价纠偏条款——意见中的"定价纠偏"从经验判断升级为量化测算。

## Overview

从团险询价单出发，**先按备案费率引擎完成报价测算（含报价纠偏与三色判定），再生成询价单"总公司核保审核意见"栏的标准五段式意见文本**。两大模块：

- **报价引擎**（references/quotation-logic.md，源自《企业团体保险自动核保报价单_v1.2》工作簿）：补充医疗六项＋意外/重疾/津贴/护理/生育备案费率全集、四档人数加权公式链、赔付判断三色判定（绿≤80% / 黄80~90% / 红>90%）、费用率19.3%与保本线80.7%。
- **意见规则引擎**（references/opinion-writing.md，源自团险核保台账1120LC 872条真实意见语料）：健康告知条款规则矩阵、赔付数据四分支判定链、风险因子条款库、结论句式库、质检十条。

语料基线结论：**零拒保零延期**——意见职能是**定价纠偏与风险条件化**，不是否决业务。报价引擎的加入使"定价纠偏"成为可复算的量化结论。

## 输入要求

| 输入 | 类型 | 说明 |
|---|---|---|
| 团险询价单 | doc/docx（必备） | 含客户结构、方案、标准/预期保费、特别约定、既往赔付史、分公司初审意见 |
| 既往核保理赔数据 | 询价单内嵌 或 台账/理赔表 xlsx（可选） | 分年度保费/赔款/赔付率；已有内嵌数据时无需另给 |

## Workflow（7 步）

1. **解析询价单** — 经 `workbuddy-local-office-edit` 的 editor_sdk 后台 `open_file` + `doc_convert_to_html` 导出全文（.doc 老格式同样支持，保存时须 `allow_format_change=true` 另存 .docx）。既往理赔数据若在单独 xlsx 中，委派 `sheet-agent` 子代理只读提取分年度数据。
2. **数据提取** — 按 opinion-writing.md §4 清单：业务类型（新单/续保/转保/自保件）、**人员分组结构**（各组人数/年龄档/性别占比/社保/连带/退休——报价引擎的输入）、险种组合与责任参数（保额/免赔额/赔付比例/选投）、分年度保费/赔款/赔付率（**标注理赔成熟度**：未到期年度只写"暂未发生赔付"，不作定价依据）、职业类别、分公司意见要点。
3. **报价测算** — 按 quotation-logic.md §9 标准流程：分组→逐组查表→人数加权→汇总→附加险→与询价单报价比对（复现法定位差异根因：简单平均/漏项/档错）→赔付判断三色（先校准人均成本）。**严守定价五铁律**（quotation-logic.md §0）：人数加权禁止简单平均、分组定价、系数表不混用、未覆盖险种不虚构、先校准再判定。
4. **规则引擎** — 逐条过触发矩阵（opinion-writing.md §2）：健康告知条款（业务类型×年龄×险种选变体＋重大既往症范围附文）→ 既往赔付数据处理条款（四分支判定链）→ 风险因子条款（14类触发即加）→ 操作合规条款。
5. **组装五段式** — 按 opinion-writing.md §1 结构编号组装：健康告知 → 赔付数据/定价纠偏 → 风险因子 → 操作合规 → 结论句（§3 句式库按当前时点取最新话术版本）。**测算结论按 quotation-logic.md §8 落地规则融入第2条**：报价构成核验、加权纠偏、三色判定结论、责任构成出入提示、对消巧合警示、引擎已知限制风险提示。
6. **质检** — 对照 opinion-writing.md §5"分公司请关注"十条自检＋报价侧自检（标准保费是否人数加权、预期价与加权标准价的真实关系、成本口径是否校准）。
7. **输出** — 两种交付：①意见全文文本（用户直接抄录询价单）；②经 editor_sdk 写入询价单"总公司核保审核意见"栏后 `save_file`（不改询价单其他内容）。落款核保人＋日期。

## 执行纪律

- **话术版本取最新**：结论句式与附文按台账版本演化取当前时点版本（2025-11起含重大既往症范围全文）。
- **数字不编造**：赔付数据条款中的保费/赔款/赔付率/建议金额必须来自询价单、理赔数据原文或本次报价测算过程；无数据走"无既往赔付数据参考"分支，不得虚构。
- **定价五铁律**：见 quotation-logic.md §0（人数加权/分组定价/系数表不混用/未覆盖险种不虚构/先校准再判定）。
- **条款顺序固定**：健康告知→赔付数据/定价纠偏→风险因子→操作合规，编号连续、条款末分号、结论句独立成行。
- **与评估技能联动**：用户已在 `gi-renewal-underwriting-eval` 跑过多情形测算时，调整建议（比例/免赔/上浮幅度）直接引用其量化结论，且比例下调建议必须同时写明"报价维持不降"（联动调价抵消效应）。本引擎测算与该技能测算冲突时，以口径更贴近本案结构者为准并写明差异。
- 询价单原件只读；写入意见仅限"总公司核保审核意见"栏。
