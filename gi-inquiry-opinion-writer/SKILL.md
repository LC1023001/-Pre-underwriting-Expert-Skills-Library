# 团险询价回复核保意见生成（总公司审核意见）

## Overview

按台账语料提炼的规则引擎，从询价单与既往核保理赔数据自动生成询价单"总公司核保审核意见"栏的标准五段式意见文本。语料基线：团险核保台账（1120LC）872 条真实意见 / 24 万字符（2024-07～2025-11），零拒保零延期——意见职能是**定价纠偏与风险条件化**，不是否决业务。

## 输入要求

| 输入 | 类型 | 说明 |
|---|---|---|
| 团险询价单 | doc/docx（必备） | 含客户结构、方案、标准/预期保费、特别约定、既往赔付史、分公司初审意见 |
| 既往核保理赔数据 | 询价单内嵌 或 台账/理赔表 xlsx（可选） | 分年度保费/赔款/赔付率；已有内嵌数据时无需另给 |

## Workflow（6 步）

1. **解析询价单** — 经 `workbuddy-local-office-edit` 的 editor_sdk 后台 `open_file` + `doc_convert_to_html` 导出全文（.doc 老格式同样支持）。既往理赔数据若在单独 xlsx 中，委派 `sheet-agent` 子代理只读提取分年度数据。
2. **数据提取** — 按 references/opinion-writing.md §4 清单：业务类型（新单/续保/转保/自保件）、人员结构（人数/年龄/性别/社保/连带/退休）、险种组合与保额、分年度保费/赔款/赔付率（**标注理赔成熟度**：未到期年度只写"暂未发生赔付"，不作定价依据）、职业类别、分公司意见要点。
3. **规则引擎** — 逐条过触发矩阵（references/opinion-writing.md §2）：健康告知条款（业务类型×年龄×险种选变体＋重大既往症范围附文）→ 既往赔付数据处理条款（四分支判定链，含具体数字）→ 风险因子条款（14类触发即加）→ 操作合规条款。定价调整幅度优先引用量化测算结论（见与评估技能的联动）。
4. **组装五段式** — 按 §1 结构编号组装：健康告知 → 赔付数据 → 风险因子 → 操作合规 → 结论句（§3 句式库按当前时点取最新话术版本）。
5. **质检** — 对照 §5"分公司请关注"十条自检（职业按实际工作内容、连带不高于主被保人、询价前后一致等）。
6. **输出** — 两种交付：①意见全文文本（用户直接抄录询价单）；②经 editor_sdk 写入询价单"总公司核保审核意见"栏后 `save_file`（不改询价单其他内容）。落款核保人＋日期。

## 执行纪律

- **话术版本取最新**：结论句式与附文按台账版本演化取当前时点版本（2025-11起含重大既往症范围全文）。
- **数字不编造**：赔付数据条款中的保费/赔款/赔付率/建议金额必须来自询价单或理赔数据原文；无数据走"无既往赔付数据参考"分支，不得虚构。
- **条款顺序固定**：健康告知→赔付数据→风险因子→操作合规，编号连续、条款末分号、结论句独立成行。
- **与评估技能联动**：用户已在 `gi-renewal-underwriting-eval` 跑过多情形测算时，调整建议（比例/免赔/上浮幅度）直接引用其量化结论，且比例下调建议必须同时写明"报价维持不降"（联动调价抵消效应）。未跑测算时按四分支判定链直接从赔付率分支。
- 询价单原件只读；写入意见仅限"总公司核保审核意见"栏。
