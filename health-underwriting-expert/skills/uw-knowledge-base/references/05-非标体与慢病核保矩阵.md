# 06 · 非标体与慢病核保矩阵

> **模块定位**：常见健康异常的核保结论对照，供快速预判与投保策略参考。
> ⚠️ **本矩阵反映行业一般规律，不代替保险公司的实际核保决定**。各公司核保尺度差异显著。
> 建库日期：2026-10-01 ｜ 维护：uw-knowledge-base

## 一、非标体核保的五类结论

| 结论 | 说明 |
|------|------|
| **标准体承保** | 按标准费率，无附加条件 |
| **加费承保** | 保费高于标准体（常见 +20%~+50%，甚至更多） |
| **除外承保** | 特定疾病/器官不保，其他照常赔 |
| **延期承保** | 暂时不能买，观察一段时间复查后再评估 |
| **拒保** | 风险过高，直接拒绝 |

> **非标体投保的目标**：不是"全部保障纳入"，而是在既有体况下争取**尽可能优的承保条件**。

## 二、★ 常见慢病核保对照矩阵

来源：咸阳新闻网（行业核保逻辑整理，可信度 **C**）｜截至 2026-09

| 慢性病 | 控制良好、无并发症 | 控制一般/轻度异常 | 控制不佳/有并发症 |
|--------|------------------|-----------------|-----------------|
| **高血压** | 多数常规医疗险可标准承保 | 部分产品除外或加费 | 多产品受限，可看防癌医疗险、惠民保 |
| **2 型糖尿病（非胰岛素依赖）** | 少数产品标准承保 | 多数除外或加费 | 基本仅防癌险 / 惠民保 |
| **1 型糖尿病 / 胰岛素依赖** | 常规医疗险受限 | 防癌医疗险为优先 | 惠民保兜底 |
| **甲状腺结节（1–2 级）** | 多数可标准承保 | 部分除外甲状腺相关 | — |
| **甲状腺结节（3 级及以上 / 穿刺待查）** | 多除外甲状腺相关 | 少数产品 | 需复查再核保 |
| **乳腺结节（BI-RADS 1–2）** | 多数可标准承保 | 部分除外乳腺 | — |
| **乳腺结节（BI-RADS 3 及以上）** | 多除外乳腺相关 | 少数产品 | 建议复查后核保 |
| **乙肝携带（肝功能正常）** | 多数可标准承保 | 部分除外肝病 | — |
| **乙肝（肝功能异常 / 有肝纤维化）** | 多除外肝病 | 需专科评估 | 基本仅限防癌险 / 惠民保 |
| **高脂血症（规律服药）** | 多数可标准承保 | 部分除外 / 加费 | — |
| **痛风（无肾功能损伤）** | 多数可标准承保 | 部分除外肾脏 | — |
| **肺结节（实性 <8mm 且稳定）** | 多除外肺部相关 | 需复查 | — |

**其他常见结论（慧择口径，可信度 C）**：
- 甲状腺结节 0–3 级或存在淋巴结肿大 → 大概率**除外承保**（除外甲状腺相关疾病）
- 甲状腺结节 1–2 级且无肿大 → 大概率**标准体**
- 甲状腺结节超声 4 级及以上且未手术 → **拒保**；手术切除超半年且病理不良 → **拒保**；病理良性 → 可标准体
- 子宫肌瘤直径 >5cm → 需尽快手术，**拒保**或**延期**（术后病理良性 + 1 年复查无异常可标准体）

## 三、★ 2026 年核保放宽项目清单（市场实践，强时效性）

来源：中国经济新闻网《2026年非标体投保怎么选》｜可信度 **C**｜**截至 2026 年**

> ⚠️ **时效性强制标注**：本清单截至 **2026 年**，各产品核保规则持续迭代，**过期即失效**，使用前须重新核实。

### 3.1 放宽的指标上限

| 项目 | 放宽后常见标准 | 说明 |
|------|---------------|------|
| **BMI** | 上限放宽至 **36** | 原多数产品上限 30–32 |
| **尿酸** | 升高至 **650 μmol/L** 以内 | — |
| **子宫肌瘤** | ≤ **6 cm** | — |
| **卵巢囊肿** | ≤ **4 cm** | — |
| **肝血管瘤** | ≤ **6 cm** | — |
| **血压** | 多数产品要求收缩压 **<160 mmHg**、舒张压 **<100 mmHg** 且无并发症 → **标准体承保** | 未诊断为三级高血压、仅某次检查达 180/110 但规律服药稳定、近半年各指标良好 |
| **三尖瓣返流 / 肺动脉瓣返流** | 纳入更宽松核保范围 | 多项从加费升级为**标准体** |
| **甲亢 / 甲减** | 纳入更宽松核保范围 | — |
| **哮喘** | 纳入更宽松核保范围 | — |
| **抑郁症 / 焦虑症** | 纳入更宽松核保范围 | — |

### 3.2 2026 策略要点

1. **先预核保、不留痕**：优先走智能核保（匿名），避免正式投保留下拒保/延期记录
2. **善用标体复核机制**：智能核保给出除外结论后，可凭**连续复查报告、稳定指标记录**申请标体复核
3. **横向比对多家**：同一份体检报告在不同公司可能得到从拒保到标准体的不同结论
4. **不留痕人工核保**：部分平台（如慧择）预核保人工核保**不留痕**，被拒保或延期不影响后续投保其他公司
5. **重视健康告知的时间范围**：问"近 2 年内是否住院"，则 3 年前手术且已康复无需告知

### 3.3 非标体投保五误区

| 误区 | 后果 |
|------|------|
| **隐瞒病史投保** | 保险公司有权解除合同、不赔、不退保费（保险法第16条）；约 30% 医疗险拒赔纠纷与此相关 |
| **被一家拒保即放弃** | 核保尺度差异显著，一家拒保不代表全部拒保 |
| **未做预核保直接正式投保** | 留下拒保/延期记录，可能进入行业共享核保数据库 |
| **忽视健康告知时间范围** | 过度告知 → 不必要的核保麻烦；漏报 → 理赔纠纷 |
| **只看产品不看平台** | 体况越复杂，平台核保协助能力的价值越突出 |

## 四、带病投保的险种路径（兜底策略）

来源：沃保保险网、深蓝保｜可信度 **C**｜截至 2026 年

| 险种 | 适用人群 | 特点 |
|------|---------|------|
| **意外险** | 慢病、既往症人群 | 绝大多数无需健康告知，仅对职业有要求 —— **带病投保入门首选** |
| **惠民保（普惠型补充医疗险）** | 不限年龄/职业/健康状况 | 需参加当地医保；既往症可按约定报销（比例可能降低） |
| **免健康告知医疗险** | 轻度慢病、高龄 | 无需填健康问卷；**但既往症及并发症多在免责范围**，主要保投保后新发疾病 |
| **防癌险 / 防癌医疗险** | 癌症术后、严重三高、糖尿病有并发症 | 健康告知极宽松；确诊癌症后符合条件费用报销约 90% |
| **慢病专属医疗险** | 乙肝、糖尿病、甲状腺结节等 | 针对病种优化核保规则 |
| **宽松核保重疾险（易核版）** | 肺结节、甲状腺/乳腺结节、高血压、糖尿病、乙肝、肾结石 | 健康告知仅 3 条左右；既往非标体/加费/除外承保史也可投保 |
| **定期寿险** | 结节、轻度三高人群 | 健康告知相对宽松 |
| **长期护理保险** | 失能人群 | 健康状况要求低 |
| **团体保险** | 在职人员 | 健康告知通常宽松 |

## 五、非标体核保的四个判断维度（通用）

```
核保评估一个健康异常
├── 维度 1：病种分级
│   └── 是什么病？控制到什么程度？有无合并症？
│       例：单纯血压偏高+规律服药+无并发症  ≠  控制不佳+合并糖尿病+有住院史
├── 维度 2：持续时间与趋势
│   └── 单次异常 vs 持续存在；好转 vs 恶化
├── 维度 3：波及范围
│   └── 单器官 → 除外该器官即可；多器官（如糖尿病）→ 多数责任不予承保
└── 维度 4：随访证据
    └── 有无连续复查报告？稳定性是否可证？→ 决定能否争取标准体
```

## 六、与其他规则的衔接

本矩阵为**概览层**。具体个案结论须结合完整医学资料综合评估，必要时由人工预核保确认。

**已沉淀的共病组合示例**：
- 甲状腺（术后+桥本）+ 乳腺 BI-RADS 3 类 → 取高 +50%，除外 + 可能加费
- 颈动脉斑块 + LDL-C 升高 → 相加，加费 + 心血管除外
- ST 段改变 + LDL-C↑ + CK↑ → 取高 ×1.3，加费 + 心血管除外
- 肺结节 Lung-RADS 2 + 肺大疱 <20mm → 同系统取高 +0，不额外加费
- 一过性高血压（恢复）+ BMI 29.7 → 取高（BMI +25），标体或轻加费
