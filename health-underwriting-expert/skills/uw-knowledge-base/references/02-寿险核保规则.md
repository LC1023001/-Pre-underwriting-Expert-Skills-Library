## 一、核保的风险度量工具

来源：行业公开资料（51Callcenter 刘春华《大话保险业务运营管理之核保》，可信度 **C**）+ 百度百科"弱体人寿保险"（**C**）

### 1.1 核心公式

| 概念 | 定义 | 公式 |
|------|------|------|
| **死亡率 M** | 某年龄人群一年内死亡比率 = 年内死亡人数 ÷ 年初生存人数 | 区分性别，来自**经验生命表**，是产品定价基础 |
| **缺陷体死亡率 M′** | 有某健康缺陷人群的死亡率（高于 M） | — |
| **死亡指数 TM** | 以特定人群死亡率为分子，标准人群死亡率为分母 | **TM = M′ / M** |
| **标准人群死亡指数** | 基准值 | **TM = 1** |
| **额外死亡率 EM** | 缺陷人群相对标准人群的额外风险 | **EM = TM′ − TM = TM′ − 1** |

> 保险公司依据行业经验数据与生命表，对特定疾病/职业设定额外死亡率（EM），据此计算加费指数。

### 1.2 核保的两个基本过程

1. **评估风险**：根据已取得的核保资料，对一个或一组被保险人、就某一特定保险产品所表现的风险程度进行评估和分类
2. **做出决定**：
   - 接受 —— 无条件（标准体）／有条件（次标准体）
   - 拒绝 —— 拒保 / 延期

## 二、被保险人的分类

| 分类 | 定义 | 承保条件 |
|------|------|---------|
| **标准体（标准风险）** | 健康状况接近精算定价产品的标准风险 | 标准费率，无附加条件 |
| **优选体** | 健康状况**优于**精算定价的标准风险 | 更低费率或更优承保条件 |
| **次标准体（弱体/次健体）** | 风险程度较高，不能按标准费率承保，但**可附加条件承保** | 加费/除外/削减给付/缩短期间 |
| **拒保体（谢绝体）** | 保险公司认为无法承保 | 拒保 |

### 2.1 次标准体的判定临界

- 行业常见口径：死亡指数**超过标准指数的 125% 或 130%** 时可判为次标准体
- 反向：额外死亡率（EM）超过一定阈值即进入次标准体区间
- **注意**：各公司阈值不同，不可一概而论

### 2.2 发展沿革（理解制度逻辑）

- 1762 年英国标准人寿开办现代人寿保险业务 → 次标准体概念雏形（仅"加征特别保险费"）
- **1896 年美国纽约人寿**基于缺陷体死亡率调查，采用**评分制方法**承保次标准体 → 现代数值评分系统的起点
- 目前绝大多数寿险公司均承保次标准体

## 三、次标准体的三种基本承保方法

| 方法 | 机制 | 适用风险类型 | 示例 |
|------|------|-------------|------|
| **① 保额削减给付法** | 按正常费率承保，但在一段期间内按比例减少保险金给付，之后逐渐趋于正常 | **递减性风险** | 刚完成手术、处于恢复/愈合期的被保险人 |
| **② 年龄增加法** | 按高于实际年龄若干岁的年龄计算保费 | **递增性额外风险** | 糖尿病、显著肥胖症 |
| **③ 征收额外保费法** | 按额外死亡率高低，征收一定额外保险费 | **固定性额外风险** | 吸烟、职业性危险、酗酒、肺结核 |

**其他限制手段**：
- 限制保额承保
- 限制保险期限承保
- 增加责任免除事项承保
- 以**特别承保同意书**载明具体承保条件

> **风险分散**：对弱体保险，自留额与最高保险金额通常订得比标准体保险**更低**。

## 四、财务核保


### 4.1 收入的定义

| 类型 | 定义 | 是否计入保额测算 |
|------|------|:---------------:|
| **赚得收入（Earned Income）** | 通过劳动所得，会因被保险人死亡或伤残而终止（工资、经营利润） | **计入** |
| **非赚得收入（Unearned Income）** | 不会因死亡/伤残丧失（房租、银行利息、股息分红） | **不计入** |

**净值 = 资产 − 负债**

### 4.2 收入替代法

> 保额 ≈ 被保险人正常工作至退休所能挣到的**总收入转换为现值**。

**北美寿险保额 / 收入倍数参考**（公开精算研究）：

| 年龄 | 年收入倍数上限 |
|:----:|:-------------:|
| 30–39 | 30× |
| 40–49 | 20× |
| 50–59 | 15× |
| 60–64 | 10× |
| 65–70 | 5× |

### 4.3 保险费财务核保

- **一般规则**：年保险费**不应超过**投保人年收入的 **30%**（行业通行口径）
- **趸缴/Top-up 保险费**：每笔 ≥50 万需人工审核缴纳保险费能力
- **PEP 筛查**：年化保险费 ≥50 万人民币的保单需进行政治公众人物（PEP）筛查

### 4.4 高保额保单所需资料（行业通行口径）

**A. 客户财务背景报告**（营销员填写）：投保目的、承揽经过、家庭及社会背景、本人及家庭成员财务状况、家庭成员保障情况、日常生活习惯及业余爱好

**B. 有效财务证明**：薪金证明/雇佣合同、经审计的公司账目/损益表/经营执照、完税凭证、银行存款证明、房地产证明、个人名下资产证明

## 五、核保信息来源（风险因素维度）

来源：行业公开资料（可信度 **C**）

| 维度 | 核保关注点 |
|------|-----------|
| **健康因素** | 既往病史、家族史、体检指标、用药史 |
| **财务因素** | 收入、净值、保额与身价匹配度、保单可持续性 |
| **职业因素** | 职业等级、职业病风险、工作环境 |
| **居住/环境因素** | 居住地风险评级、生活环境 |
| **业余爱好** | 高风险运动（潜水、赛车、跳伞、登山） |
| **道德因素** | 逆选择、欺诈倾向、投保目的 |
| **险种因素** | 体现投保目的（寿险 vs 意外险 vs 健康险） |
| **保额与缴费** | 保额是否与身价匹配、保单可持续性 |

**核保资料类型**：投保单/告知问卷、体检报告、病历资料（门诊/住院）、医师报告（APS）、财务证明、职业证明、既往核保记录（行业共享数据库）

## 六、老年核保（≥60 岁核心）


**关键点**：
- 死亡率/疾病发生率随年龄**指数级上升**，评点假设的影响被**不成比例放大**
- 老年人**正常值更高**的指标：体格（BMI）、血压、总胆固醇、NT-pro-BNP、PSA → 不可套用年轻人参考值
- 额外死亡率的**作用力随年龄衰减**（impaired annuity underwriting）
- 老年核保必查：常规医疗照护、处方药使用、交通意外、行动能力、驾驶、跌倒史、吸氧、认知能力
- **IADL**（工具性日常活动）：理财、驾驶/公共交通、购物烹饪、家务、沟通、用药管理
- **ADL**（日常生活活动）：行走、进食、穿衣修饰、如厕、洗浴、转移
- **最大扣点限制**：85 岁常见上限 +150；90 岁常见 +0

## 七、职业核保

**职业风险四级分类**：

| 等级 | 定义 | 费率倍数 |
|:----:|------|:-------:|
| I | 不从事体力劳动的专业/管理/行政/文员 | 1× |
| II | 管理监督类手工艺人和商人；非危险职业轻体力熟练操作工 | 1.5× |
| III | 非危险职业体力劳动熟练操作工 | 2× |
| IV | 重体力劳动或面临特殊危险的熟练/半熟练操作工 | 3× |

**特殊职业核保注意**：
- 商业潜水、商业航空、军队等 → 多数拒保 DI（收入保障险）
- 职业运动员 → 按职业等级评估，特定保额限制

## 八、业余爱好 / 高风险运动核保

| 活动 | 核保处理要点 |
|------|-------------|
| 水下潜水 | 超过 40 米深度 → 加费或除外 |
| 赛车（汽车/摩托车） | 业余赛车 → 加费；**职业赛车 → 拒保** |
| 跳伞 | 不超过特定次数 → 加费；**职业 → 拒保** |
| 登山 | 8000 米以上 → 拒保 |
| 通用规则 | 休闲运动评点以 **‰** 表示；**>2‰ 通常拒保**（多数险种） |

## 十、寿险核保结论速查

| 结论 | 英文 | 条件 |
|------|:----:|------|
| 标准体承保 | SER | 无异常健康/非健康风险因素 |
| 加费承保 | +EM | 特定风险因素，额外死亡率 EM 加收 |
| 除外责任 | Excl | 特定疾病/部位/系统不予保障 |
| 延期 | PP / Defer | 暂不接受，需观察后重评 |
| 拒保 | Dec | 不接受投保申请 |

**次标准保单处理流程（行业通行口径）**：
1. 核保部发照会并附"修订计划"或"不保事项"
2. 客户签名同意
3. 如需加费则补交追加保险费
4. 客户健康状况改善后可申请重审（通常为生效第一个周年日后）
