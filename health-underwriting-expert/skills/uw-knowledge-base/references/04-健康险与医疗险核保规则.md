## 一、健康险核保结论光谱

来源：LIA（新加坡人寿保险协会）《Guide to Medical Underwriting for Life Insurance》2024｜可信度 **B**

| 结论 | 英文 | 说明 |
|------|:----:|------|
| **标准体承保** | Offer Standard Terms | 风险评估为标准风险，按标准费率承保，无额外保费、无除外。**大多数申请人属于此类** |
| **加费承保** | Offer with Loading | 因超重/既往症等原因，需加收额外保费，可能同时附加除外 |
| **除外承保** | Offer with Exclusion | 特定疾病及其关联风险被排除在保障之外 |
| **延期承保** | Postpone Cover | 因高风险与不确定性（如待做手术）暂不受理 |
| **拒保** | Decline Cover | 风险不可接受（如未控制的高血压） |

### 1.1 ★ 除外责任的适用范围判断（LIA 原则，极其实用）

| 情形 | 核保处理 | 示例 |
|------|---------|------|
| 疾病**不影响其他器官** | 可承保，但将该具体疾病及关联风险**除外** | 失聪 → 除外"由失聪直接或间接导致的任何残疾" |
| 疾病影响**特定部位/系统** | 对该部位/系统设除外，其他照保 | 椎间盘突出 → 寿险可标体，但 TPD 与住院责任对"脊柱"设除外 |
| 疾病**涉及多器官** | 多数责任（TPD、重疾、住院）**均不予承保** | 糖尿病（累及心、眼、神经、皮肤、肾）；控制不佳时可能**不给任何保障** |

> **核保含义**：外除范围与疾病的"器官波及范围"成正比。**多系统疾病 = 高拒保概率**。

## 二、既往症（Pre-existing Condition）核保

来源：中民保险、慧择保险网、深蓝保（可信度 **C**，多源互证）

### 2.1 既往症的定义（比直觉宽得多）

条款中的既往症通常包括：

1. 投保前**已确诊**的疾病（哪怕只是甲状腺结节、乳腺结节）
2. 投保前**已有明显症状**（长期腹痛、咳血、不明原因消瘦）
3. 投保前**已接受过治疗**（哪怕只是门诊开药）
4. **体检报告上的异常指标**（高血压、脂肪肝、尿酸高、肺结节）

> 释义口径："投保前已患的、被保险人**已知或应该知道**的有关疾病和症状"

### 2.2 ★ 关键区分：核保通过 ≠ 既往症可赔

| 环节 | 判断标准 | 结果 |
|------|---------|------|
| **健康告知** | 是否符合告知要求 | 决定**能不能买** |
| **核保结论** | 风险评估 | 标准体/加费/除外… |
| **免责条款** | 是否属除外责任 | 决定**能不能赔** |

> **实务铁律**：即使智能核保给出"正常承保"，若条款约定"既往症免责"，该既往症相关费用**仍可能不赔**。
> **例外**：条款明确写"如实告知且审核通过的，不算既往症"的产品（如部分产品），核保结论为正常承保则该病可赔。

**可保既往症的险种**：
- 医保（不限健康状况）
- 惠民保（不限健康状况，但既往症报销比例可能降低）
- 免健康告知医疗险（指定几类重疾除外，其余既往症可保）
- 部分可附加既往症保障的中高端医疗险

### 2.3 既往症核保结论频谱

正常承保 / 除外承保 / 延期承保 / 加费承保 / 拒保

## 三、智能核保（Smart Underwriting）

来源：行业公开资料（可信度 **C**）

### 3.1 智能核保 vs 人工核保

| 维度 | 智能核保 | 人工核保 |
|------|---------|---------|
| 形式 | 匿名问卷，系统即时给结论 | 提交病历/体检/复查资料，人工审核 |
| 速度 | 秒级 | 数日 |
| **留痕** | **通常不留拒保记录**（"不留痕"） | **可能留下拒保/延期记录**，进入行业共享核保数据库 |
| 适用 | 常见健康异常、体况简单 | 体况复杂、智能核保未通过 |
| 策略 | **优先使用**（先试后投） | 准备好完整资料后提交 |

### 3.2 智能核保的四道关口

1. **病种分级**：是什么病、控制到什么程度、有无合并症
2. **承保方式选择**：在五类结论中给出最优解（而非"绕过告知"）
3. **核保前置评估**：填写健康告知时同步给出"预计结论"，正式投保前就知道能否买、什么条件
4. **长期续保与除外追踪**：复查好转后能否申请解除除外责任

### 3.3 智能核保的固有风险（★核保视角的反向教训）

| 风险 | 说明 |
|------|------|
| 依赖被保人主动告知 | 仅凭告知，不主动调取医疗记录 → 存在**漏检风险** |
| 规则不细分 | 如甲状腺癌术后智能核保通常只区分"癌症史 + 术后年限"，不细分 N0/N1a/N1b → 可能过松或过严 |
| 规则迭代 | 各产品智能核保规则**持续迭代**，结论不可依赖历史经验 |
| 假阴性 | 体检指标"看似正常"但动态监测确有异常（如静息 ECG 正常但动态心电图（Holter）捕捉到间歇性异常，须以动态监测为准） |

> **核保含义**：智能核保的宽松 ≠ 风险不存在。核保评估必须核实**完整医疗记录链**，单时间点"正常"不代表疾病消失。

## 四、医疗险核保要素

来源：谱蓝保、慧择、沃保（可信度 **C**）

| 要素 | 核保关注点 |
|------|-----------|
| **健康告知时间范围** | "近 6 个月"/"近 1 年"/"近 2 年"/"近 3 年"/"曾经" —— **逐条确认时间范围**，避免过度告知 |
| **等待期** | 疾病等待期常见 **90 天**；意外无等待期；等待期内出险不赔 |
| **免赔额** | 影响核保结论与产品选择（0 免赔 vs 1 万免赔） |
| **保证续保期** | 保证续保 6 年/20 年/终身 —— 核保考虑长期风险敞口 |
| **报销范围** | 二级及以上公立医院普通部 / 特需部 / 私立 / 海外 |
| **社保结算** | 未走社保结算，报销比例降档（常见降至 60%） |
| **职业类别** | 医疗险通常仅 1–4 类，高危职业受限 |
| **年龄上限** | 如 60 岁后部分产品不可投 |

**免责条款通用限制**：
- 美容整形、减肥相关费用不赔
- 酒驾、无证驾驶导致的意外不赔
- 既往症及投保前已有疾病（多数产品）
- 特定治疗/医院不赔

## 五、健康险核保评点（慕再口径）

来源：慕再 MIRA 手册｜可信度 **B**，详见 `01` 文件 1.6

**住院津贴 / 手术保险（Health）**：
- 医学评点：0（标准）/ +50%（+50% 健康险风险保费费率）/ **Dec 拒保**
- 慕再建议：最低 25%EM，最高 +100%EM
- **除外责任不超过 2 项**
- **EM >100% 或需 >2 项除外 → 建议拒保**

**长期看护险（LTC）**：
- 评点：10 / 25 / 35 / 50 / 75 / 100 % 额外发病率；**≥150 拒保**
- 六项 ADL：洗浴、更衣、个人卫生（入厕）、行动、饮食（摄食）、大小便自制

## 六、健康险核保的行业现状（2026 市场口径）

来源：中国发展网、界面新闻、行业媒体（可信度 **C**）

| 指标 | 数值 |
|------|------|
| 2025 年我国健康险保费规模 | **9,973 亿元**（接近万亿），增速放缓 |
| 慢病患者规模 | 超过 **4 亿人** |
| 带病体保险市场规模（2024） | **120 亿元**，同比增速约 **50%** |
| 潜在保费规模 | 高达 **1.5 万亿元** |
| 因无法通过健康告知被拒保的带病体 | 约 **三成** |
| 尚未意识到自身仍具备投保可能 | 约 **两成** |
| 医疗险拒赔案例中与带病投保告知瑕疵相关的纠纷 | 近 **30%** |
| 智能核保争议投诉量占比 | 由初期 <5% 升至近两年约 **18%**（待核实） |

**2026 核保趋势**：市场从"规模扩张"转向"高质量发展"；核保与理赔双端提效（AI 辅助核保 + 重疾先赔）；多家险企**放宽核保标准**（见 `06-非标体与慢病核保矩阵.md`）。

## 七、AI 辅助核保的实践（合规参照）

来源：中国发展网报道（海保人寿案例）、界面新闻（保诚"AI核保师"）｜可信度 **C**

| 案例 | 做法 | 规模/定位 |
|------|------|----------|
| **海保人寿** | 重疾险核保场景上线 **AI 核保辅助决策**：OCR 智能识别 + 垂直大模型分析 + 核保评估知识库 | 累计识别 **5 万余张**健康证明图片，为 **4,500 余件**重疾保单提供**人工核保辅助结论** |
| **保诚（Prudential）** | 与阿里云共同研发 **"AI 核保师"（AI Underwriter）** | 数分钟内就承保、除外责任、额外保费、所需补充资料提供**初步核保指引**；**定位为协助理财顾问，非替代人工** |

**行业共识**：
- 主流做法是 **"AI 初次核保 + 人工复核"** 的双重协作
- 人的核心价值：**理解客户需求 + 承担最终决策责任**
- 头部寿险公司内部人士："本着对客户负责的态度，也不可能 100% 由 AI 来处理客户的需求"

**合规约束**（见 `02` 文件第六节）：
- 金发〔2026〕8号：承保理赔类生成式 AI 属**高风险应用**，须经风险管理委员会批准
- 智能核保系统需具备可解释性、留存决策日志（≥5 年）、人工复审兜底

## 八、健康保险监管框架（2025—2026）

### 8.1 《关于推动健康保险高质量发展的指导意见》（金发〔2025〕34号）★

| 项 | 内容 |
|----|------|
| 发布机构 | 国家金融监督管理总局 |
| 发布/成文日期 | **2025-09-30** |
| 文号 | **金发〔2025〕34号** |
| 阶段目标 | 到 **2030 年**，形成满足全人群、全生命周期多样化需求的**多层次健康保险市场格局**，建成更健全的健康保险监管制度体系 |
| 上位依据 | 国务院 2024-09《关于加强监管防范风险推动保险业高质量发展的若干意见》 |
| 可信度 | **A**（文件本体，官网可溯）｜解读来源：江苏省保险学会、人民网、21 财经 |

**四大险种改革方向（★标注核保相关）**：

| 险种 | 核心要求 |
|------|---------|
| **商业医疗保险** | 构建**全覆盖、多层次**产品体系；将**医疗新技术、新药品、新器械**纳入保障；**首次**提出支持**个人账户式长期医疗保险**；健全长期医疗险费率调整机制；鼓励长期医疗险**按风险类别定价**；**★鼓励开发惠及带病群体、罕见病群体的商业医疗保险产品**；规范发展短期医疗保险与城市定制型（惠民保）业务 |
| **商业长期护理保险** | 全面开展**人寿保险责任与护理支付责任转换**业务；对接居家/社区/机构护理；退休后提供满期保障 |
| **失能收入损失保险** | 扩大覆盖人群范围 |
| **疾病保险（重疾险）** | **★结合疾病谱变化及时修订疾病定义**；**支持监管评级良好的公司开展分红型长期健康保险业务**（分红型重疾险自暂停 22 年后重启） |

**其他要点**：强化**总精算师管理责任**，建立**可检视、可计量的健康保险精算回溯机制**，完善精算参数动态调整规则；完善再保险机制运用；推进**数智化转型**（规范应用 AI、大数据，优化承保理赔流程）；严厉打击恶性竞争、销售误导、**不合理拒赔**等行为。

> **核保含义**：这是当前健康险核保的**上位政策框架**。三个直接影响核保的方向——① 带病体/罕见病产品成为明确定向（**非标体核保需求上升**）；② 疾病定义将随疾病谱"**动态修订**"（与重疾定义"至少每 5 年评估"机制双重驱动）；③ 分红型重疾险重启（核保需兼顾分红账户与保障责任的交互）。

### 9.1 产品端"红线"联动：人身保险产品负面清单（2026版）

来源：金融监管总局人身保险监管司 2026-04-08 下发（详见 `02` § 七）｜可信度 **B**

与健康险核保直接相关：
- **医疗险**不得设置**过高免赔额、过低赔付比例**，定额给付型医疗津贴不得保额过低；**不得将处方审核责任转嫁第三方**（保险公司承担主体责任）。
- **护理险**不得将非终身护理保险设计成"增额终身寿"形态（防理财化）。
- **精算**：健康险须考虑**医疗费用通胀**因素；生命表须匹配 **2026-01-01** 实施的第四套生命表。

> **核保含义**：医疗险"低保障、高噱头"引流设计被禁止 → 核保在评估医疗险责任范围与赔付比例时，应以合规责任设计为前置条件；护理险形态受限 → 核保关注点从"储蓄属性"回归"护理保障属性"。

## 十、健康险核保输出模板（建议）

```
【健康险核保评估意见】
一、被保险人：年龄 / 性别 / 拟投保险种 / 保额
二、健康告知核查：逐条对应（问什么、答什么、是否需补充）
三、医学资料摘要：异常项目 + 关键数值 + 时间
四、既往症判定：是否构成既往症 / 是否已如实告知
五、核保结论：[标准体 / 加费 / 除外 / 延期 / 拒保]
```
