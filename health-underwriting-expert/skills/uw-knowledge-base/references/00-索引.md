## 二、可信度分级

| 级别 | 含义 | 使用方式 |
|:----:|------|---------|
| **A 权威** | 监管文件原文、国家标准、行业规范原文 | 可直接作为规则依据 |
| **B 可靠** | 行业协会、精算师协会公开发布 | 可作为方法学依据 |
| **C 参考** | 行业媒体、经纪平台、培训机构整理 | 仅作参考，需交叉验证 |
| **D 待核** | 单一低可信源、二手转述、数值存疑 | 不得作为依据，仅登记待核实 |

**输出时必须附**：`来源 | 日期 | 可信度`

## 四、更新机制

- **触发方式**：对专家说「**更新核保知识库**」，即执行一轮「扫描 → 去重 → 分级入库 → 版本化」
- **巡检源**：见 `07-数据源清单.md`（P0 监管与标准类优先，P1 行业实践类按月扫描）
- **去重**：以 `hash(标题 + 核心数值 + 标准编号)` 生成指纹比对
- **入库门槛**：
  - A / B 级新规则 → 直接入库
  - C 级市场实践 → 需 ≥2 个独立来源互证，且必须标注"截至 YYYY-MM"
  - D 级存疑 → 只登记，不写入正文
- **冲突处理**：监管 / 标准类一律以官方原文为准；不同来源的口径差异**并列保留，不强行统一**
- **落盘位置**：
  - 本目录（`references/`）= **出厂基线**，随专家包升级而更新
  - 个人沉淀区 `~/.workbuddy/experts-data/health-underwriting-expert/` = **你自己的累积成果，升级不覆盖**
