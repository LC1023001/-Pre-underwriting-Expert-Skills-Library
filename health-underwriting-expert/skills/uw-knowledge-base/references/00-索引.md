## 三、与其他核保技能的协同（方法学分工）

> 下图说明**通用方法学分工**，具体技能包不随本专家包分发。

```
                ┌───────────────────────────────┐
                     │  uw-knowledge-base（规则层）   │
                     │  监管规范 + 再保方法学         │
                     │  + 非标体矩阵 + 数据源          │
                     └───────────┬───────────────────┘
                                 │ 提供规则依据
        ┌────────────────────────┼────────────────────────┐
        ▼                        ▼                        ▼
  ┌──────────────┐      ┌──────────────────┐     ┌──────────────────┐
  │  病种级评点库  │      │ 重疾险个案核保评估 │     │ 同业规则横向对照   │
  │ （Gen Re 体系）│      │ （共病矩阵+案例）  │     │ （方法学框架）     │
  └──────────────┘      └────────┬─────────┘     └──────────────────┘
                                  │
                                  ▼
                       ┌────────────────────┐
                       │  重疾险理赔审核     │
                       └────────────────────┘
```

- **规则要查源头** → 本技能 `01`（再保评点方法学）/`02`（监管规范）
- **具体病种评点** → 病种级评点库（再保评分体系，与本库方法学并列，不换算）
- **个案出结论** → 重疾险个案核保评估技能
- **同业尺度对比** → 同业核保规则参考（方法学框架，不含机构专有数值）

> ⚠️ **边界声明**：本技能仅提供**公开可溯源的规则方法学**。各机构专有核保细则、免体检限额数值表、内部核保手册均**不在收录范围**，实务须以承保机构现行规程为准。

## 五、使用红线

1. 所有规则引用**必须带溯源三元组**：`来源 | 日期 | 可信度`
2. **不得混淆三套评点体系**：慕再 EM ≠ 瑞再 Table ≠ Gen Re 评分
3. 市场实践类条目**必须带时效标注**，过期即失效
4. 冲突时**以现行有效监管文件为准**
5. 知识库输出为**辅助参考**，最终核保决定由持牌核保人员依据公司规程作出
