## 结论

- 综合结论：**延期（PP）**——三项性质未明异常（左肺下叶炎性病变、CK 升高、铁蛋白持续上升）触发"病情性质未明确"延期标准
- 排查后预估：若炎性病变吸收/肺结节 6-12 月稳定/CK 复查正常/铁蛋白定性良性 → 重疾**除外肺部 + 轻加费（血脂）**或标体；医疗**除外呼吸系统 + 肝病相关**
- 风险等级：**中**（基础生命指标良好，但多系统新发异常 + 血脂趋势恶化 + 斑块史存疑）
- NRS（排查定性后方向）：肺结节首检=0~+25 + 血脂异常=0~+25 + CK=+25~+50 + 铁蛋白=排查因子 + 脂肪肝/甲状腺TR2/肾结晶/前列腺钙化=0

## 观察点（知识库未覆盖新边界，个案观察，待多案验证）

1. **血清铁蛋白升高核保**——知识库检索"铁蛋白/ferritin"仅命中 CL-46 的"血清铁升高+UIBC偏低（铁蛋白未查）"，与本案"铁蛋白本身升高"是**不同指标**（铁蛋白=铁储存+急性期反应蛋白，血清铁=转运态铁）。本案铁蛋白 471.5 持续 3 年上升 + 脂肪肝 + 血脂异常的**代谢/炎症模式**是常见临床组合，但引擎无专门评点表。候选计数器=**1**；方向：铁蛋白轻中度升高（<2×ULN）+ 肝功正常 + 无贫血 → 多为代谢/炎症相关性升高（脂肪肝/代谢综合征/亚临床炎症），排查排除血色病（需转铁蛋白饱和度/基因）与肿瘤后 → 0~+25；持续上升趋势 + 原因未明 → 触发延期排查（本案路径）。
2. **颈动脉斑块"跨机构消失"**——血管斑块一般不会自行消退，2024/2025 双次报"左侧颈动脉斑块形成"、2026 报"未见"，高度提示**跨机构超声判定/设备差异**。强化 CL-53 已有原则"跨机构'未再报'不得判消失"的**血管维度**又一例证。候选计数器=**1**；方向：斑块史存疑时不得据此直接否定 ASCVD 风险（尤其叠加 LDL-C 升高），须复查颈动脉超声定论后方可确认是否解除斑块史告知；若确为误报则解除，若复查仍有斑块则按"斑块+LDL-C 升高"评点 +50~+75。
3. 肺结节实性/磨玻璃 3mm 首检无对照 → 再次命中「实性首检无对照分档」（v1.6.6 三案验证档，第 5 例方向）；CK 升高+CK-MB 正常 → 基线 v2.9 规则内（1-2×ULN 原因未明档）；脂肪肝/甲状腺 TR2/肾结晶/前列腺钙化 → 均基线规则内，无新边界。
