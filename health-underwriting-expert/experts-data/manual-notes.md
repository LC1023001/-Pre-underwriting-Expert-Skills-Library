# 授权手册知识沉淀区（manual-notes）——RGA / Munich Re / Swiss Re 等在线核保手册唯一合规入库载体

> 配套规则：local-rules **LR-10**。本文件承接授权访问的再保在线核保手册的要点沉淀，与 kb-clues（个案线索）、cases（个案评估）、local-rules（方法论规则）并列。
>
> **合规红线（LR-10）**：禁止爬虫批量抓取/镜像/整站复制；禁止手册原文整段录入；禁止成段复制内容对外输出。唯一许可路径 = 按需查阅 → 自研语言提炼 → 按本模板录入。

---

## 使用方式

1. 日常评估遇到具体病种/风险点时，登录手册**按需查阅**对应章节；
2. 用**自己的语言**提炼核保判断要点（思考逻辑、考虑因素、结论方向）；
3. 按下方模板在文件末尾追加条目，编号 MN-三位递增（MN-001…，同 kb-clues 的 CL- 计数器惯例）；
4. 个案评估引用时，写入报告依据行，格式：**"B级（RGA手册§X要点，MN-003，访问2026-11-20）"**；
5. 当某条要点沉淀出可复用方法论并经多案验证后，可升格为 local-rules 规则条目（在关联字段注明升格去向，本条保留作溯源）。

- **病种/风险主题**：硬斑病与系统性硬化症在重疾核保中的分型及病程分层
- **查阅日期**：2026-11-23
- **来源**：RGA Global Underwriting Manual（GUM）§ Progressive Systemic Sclerosis（进展性系统性硬化）→ 重大疾病保险评点页（用户授权登录查阅并提供截图）
- **适用险种**：重疾险（仅限本页；寿险、医疗险未见该页，不外推）
- **要点提炼**（自研语言，≤200字）：GUM将硬斑病、皮肤弥散受累、CREST及进展性系统性硬化置于同一主题页，但分别按分型与病程处理。硬斑病的重疾结论随确诊年限改善：极短期延期，中期存在明显额外评点，三年以上进入零评点方向。皮肤弥散受累或CREST即使稳定无进展，五年内仍从严，五年以上转医学顾问个案；进展性系统性硬化为拒保方向。
- **结论方向**：硬斑病按确诊年限由延期/明显加费逐步改善，三年以上可向标准体方向发展；系统性硬化及CREST显著更严，进展性系统性硬化拒保。
