# 个人沉淀区规则（local-rules）——升级不覆盖

> 本文件是专家包只读基线之外的**规则增量层**，优先级高于包内基线中的冲突条目。

---

## 规则 LR-01：引用来源准入门槛（2026-10-10 修订，用户指令）

**触发背景**：用户指出核保评估引用新闻类/软文类文献不可取——出处不明、易被信息灌注失真经验。原规则允许 C 级（行业媒体/经纪平台）作为"参考"级依据，现予废止。

**规则内容**：

1. **核保结论的直接依据仅限 A/B 级**：
   - A 权威：监管文件原文（金融监管总局/原银保监会）、国标（GB/T）、《保险法》等法律原文
   - B 可靠：中国保险行业协会、中国精算师协会、LIA（新加坡人寿保险协会）等国际专业组织、再保险公司核保手册（Munich Re / Swiss Re / SCOR）、权威核保教材
2. **C 级（行业媒体/新闻稿/经纪平台/软文）与 D 级一律降级为"线索层"**：
   - 仅可作检索线索与方向提示，**不得作为核保判断依据**
   - 严禁引用 C/D 级来源的数值、阈值、档位、结论范围支撑判断
   - 仅有 C/D 级支撑时，结论标注 **"实务线索，需人工核保确认"**，不给具名数值
3. **C 级多源互证不升级**：媒体互转常为同一信息源灌注（伪多源），≥2 个"独立"来源不构成升级为依据的条件——此条覆盖原"入库门槛：C 级需 ≥2 个独立来源互证"规则
4. **报告溯源表分层**：依据表只列 A/B 级条目；C/D 级线索单独成节，标题固定为"实务线索（需人工核保确认）"

**效力**：本条已同步写入专家定义文件「引用铁律」「注意事项」，即使包升级覆盖定义文件，本沉淀区条目仍生效。

## 规则 LR-04：评估报告输出维度规范（2026-10-13，用户纠错触发）

**问题**：预核保结论表中曾出现「智能核保」与重疾险/医疗险/意外险并列为一行的错误——「智能核保」是**核保渠道与方式**，不是险种，两者不属同一分类维度，禁止在任何"按险种列举"的表格、清单、摘要中并列混排。

**规范**：
1. **险种维度**（按产品类型）：重疾险、医疗险、防癌险、寿险、意外险、年金险等；
2. **渠道与方式维度**（按承保通道）：智能核保、人工核保、预核保、再保咨询等；
3. 两维度在报告中**分区呈现**：险种维度进入「核保结论」表；渠道维度进入「投保策略建议」章节；
4. 若需交叉说明（如"重疾险经智能核保大概率拦截"），在策略章节以文字表述，不进入险种结论表。

**性质**：输出规范类修正（非数值规则），由用户对 UW-20261013-ZJX 案报告的纠错触发，属个案沉淀回路（回路1）入库。
