## CL-01：心律失常（室早/房早）核保方向线索（截至 2026-10）

**登记背景**：2026-10-15/10-16 两案形成"偶发 vs 频发/二联律"分水岭对照，具名 A/B 级档位仍缺（深挖队列第 2 位）。

**C 级来源方向观察**（美/英经纪平台多源一致，媒体互转风险仍在，不构成互证升级）：
- 室早（PVC）/房早（PAC）**无器质性心脏病、无症状** → 多数载体"not rated"（不加费），可控药物替代治疗 → 标准费率附近；
- PVC/PAC 为"常见、多为良性异位搏动"，结构性心脏正常时不显著影响死亡率——与 LR-05 方法论的功能性早搏定性路径方向一致；
- 持续性心律失常（房颤/室速/WPW）显著区别于早搏，核保 scrutinize 程度不同；房颤单次发作+高龄+控制良好可争取标准，多次发作→次标准；
- 消融成功（恢复窦律+无抗心律失常药+随访监测阴性，通常 30 天事件记录仪或复查 Holter）→ 优于长期药物控制路径；
- 未完成 EKG/Holter 等检查的心律失常申请 → 常见 postponement（延期）——与 10-16 案"资料缺口型延期"结论方向一致。

**来源**：heartlifeinsurance.com / careproinsurance.com / over50lifeinsure.com / iaminsured.co.uk（均为 C 级经纪平台）+ 深蓝保问答（C，LR-02 已列降级清单）
**用途**：仅提示"国际市场对无器质性早搏普遍不加费"的方向，**待 LIA/再保手册 A/B 级档位取回后方可作为依据**。

## CL-02：结肠腺瘤/息肉核保方向线索（截至 2026-10）

**登记背景**：2026-10-20 乙结肠腺瘤案（UW-20261020-LXY）+ 10-09 Barrett 案，消化系统癌前病变具名 A/B 级档位缺（深挖队列第 1 位，3 案累积）。

**C 级来源方向观察**（美/英经纪平台）：
- 良性息肉已切除 + 监测肠镜阴性 + 维持监测节奏 → "标准或接近标准费率"；切除后建议**至少 6 个月**再申请（恢复期内的申请可能 postponement）——与本案"切除后 6-12 个月复查肠镜阴性"复议路径方向一致；
- 评估要素：息肉病理类型（增生性/腺瘤性/进展期）、个数、高级别异型增生、监测依从性、伴随疾病；
- 进展期病理（高级别异型增生）/反复复发/监测中断 → table rating（美式每档约+25%）或延期；
- 息肉未切除 → 通常拒保或延期至切除。

**B 级边缘来源（时效存疑，暂列线索）**：Munich Re 专家（Hélène Michaud/Joan Tolan）在 Advisor.ca 刊载的癌症家族史核保文章（**2009 年**）——结肠癌家族史评点 +50、结肠镜阴性可抵减 25 分（净 +25）。年份久远且为期刊转述，按 LR-01 从严暂列线索，待 Munich Re 正式手册原文核实。

**来源**：insurancebyheroes.com / over50lifeinsure.com（C 级经纪平台）；advisor.ca Munich Re 撰文（B 级边缘，2009）
**用途**：确认"切除+阴性监测→标准体方向"的国际市场共识方向，待再保手册 A/B 级分层档位取回。

## CL-10：附件畸胎瘤/混合性占位核保条目缺口（截至 2026-10）

**登记背景**：2026-10-27 云*霄案首例——左侧附件区混合性强回声光团 42×26mm 报告描述"畸胎瘤可能"（性质待定），无溃疡、无既往影像对照。

## CL-24：甲状腺"混合回声（囊实性）"结节的成分/回声维度互斥性与分级体系选择（截至 2026-10）

**登记背景**：2026-10-30 卫\*媛案（30岁女，甲状腺双叶多发混合回声结节最大4mm、ACR TI-RADS 2 级、纵横比<1 境界清无血流、8.5个月跨机型对照稳定）。用户追问："混合回声是否应按部分低回声结节处理给除外？"

**缺口确认**：ci-underwriting 引擎甲状腺节仅有"TI-RADS 1-2级→NRS 0 标体／3级→+25 延期／4-5级→延期或Dec"三档，**未区分结节超声描述的"成分"维度与"回声"维度**，亦无"混合回声/囊实性"独立条目。实务上核保员易据"混合回声含实性成分→实性成分可能低回声"自行升级，造成无依据加码。

**B级锚点（可作依据）**：
1. **ACR TI-RADS 2017**：成分与回声为两个独立评分项——成分（囊性/几乎完全囊性 0；海绵状 0；**囊实混合 1**；实性/几乎完全实性 2）／回声（无回声 0；高或等回声 1；低回声 2；极低回声 3）。**囊实混合的成分权重低于实性**。
2. **ACR 对囊实混合结节的评分规则**：仅对**实性成分**评回声、边缘、强回声灶。推演：混合(1)+实性成分低回声(2)+0+0+0=**3分→TR3**；故 **TR2 与"实性成分低回声"在 ACR 评分上互斥**——报告既评 TR2，内禀即实性成分未被判为低回声。
3. **C-TIRADS 2020（计数法）**：垂直位／实性（低回声或低回声为主）／极低回声／点状强回声／边缘模糊不规则或甲状腺外侵犯 各+1；纯囊性、海绵样、伴彗星尾点状强回声 −1。分类：-1→2类（0%）；0→3类（**<2%**）；1→4A（2-10%）。**大部分囊实性、类蜂巢状混合回声结节归 C-TIRADS 3 类**。
4. **口径独立**：C-TIRADS 3类 ≠ ACR TR3，两套体系的恶性率、FNA 阈值、随访阈值定义不同，**严禁换算**（引用铁律第4条）。
5. **沉淀区反例**：2026-10-27 案（38岁女）混合回声 9.2×7.6×6.0mm 结节因形态欠规则+点状强回声+血流 → ACR TR**4**。佐证"混合回声"本身非升级理由，升级来自伴随恶性特征（形态、微钙化、血流、纵横比）。

**实务方向**：混合回声/囊实性结节核保按"**分级结论优先 + 恶性特征计数 + 分级体系核实**"三要素推导：
- 报告已具名分级且无恶性特征 → 以分级结论为准，**不得据描述词自行升级**（无源加码）；
- 分级体系未标注或疑似经验性分级 → 补件：①实际采用 ACR 2017 还是 C-TIRADS 2020 ②实性成分回声描述（等/低/极低）；
- 核实为低回声或改评 3 级 → 转引擎 TI-RADS 3 档（+25，除外甲状腺或延期随访重评）；
- 甲状腺结节的**常规补件优先级**：甲功三项 > 分级体系/回声描述。

**用途**：同类"混合回声/囊实性甲状腺结节"个案参照，避免成分/回声维度混淆导致的过度除外；待第2例验证后考虑入引擎内分泌节甲状腺小节（建议新增"囊实性结节评分规则"条目）。

**检索方向（待 A/B 级来源）**：慕再MIRA/瑞再Life Guide血液系统章节脾大评点（splenomegaly rating page）；《中国地中海贫血防治指南》（中华医学会血液学分会）基因携带者脾大发生率与转归；LIA核保指南血红蛋白病章节。

**登记背景**：候选计数器"肝内结节未定性"达3例阈值，2026-11-04启动合并整理评估。三案要素对比：

1. **描述性结论≠确诊**：定性表述全部为"可能/拟/未定/未除其它"——核保落档禁止按"血管瘤"评0点。既有非标体矩阵"肝血管瘤≤6cm可承保"（B级）的前提是**确诊+定量**，三案全部卡在确诊环节，该条目对"未定性"场景不适用；
2. **缺口两种形态分型**：定量缺口（大小未载→补超声定量复查）vs 定性缺口（性质未明→补影像定性）——照会清单按形态分型开列，不一刀切要求增强MR；
3. **三案均未闭环**：报告建议复查/进一步检查后投保时未见随访结果——属"未闭环发现"路径族（与"医嘱手术未执行"计数器同源结构：发现→建议→未执行→未落档）；
4. **概率低≠可豁免**：年轻女性+AFP正常+无肝硬化背景下肝内占位恶性概率低（血管瘤为最常见良性肝肿瘤），但核保不得以流行病学概率替代个案定性——"先定性再落档"。

**定性手段阶梯（照会模板）**（标"实务线索，需人工核保确认"）：
超声定量复查 → 超声造影（CEUS）→ 增强CT → **增强MR（±肝胆特异性对比剂Gd-EOB-DTPA，定性首选，无辐射适合年轻女性）** → 必要时MDT/活检（极少需要）。

**核保处理路径（三步法固化）**：
- **第一步（未定性期）**：不评0、不直接除外——作为补件项/延期触发项处理。**未定性期不除外（除外的是疾病不是检查），定性后才具备除外对象**；

8. **早产严重度分层候选（第3例增量，待多案验证）**：孕30-34周极早产AGA无严重并发症、追赶生长良好者，重疾观察窗或可按"纠正6月~1岁"档执行（医疗险通常出院满1年），与晚期早产通行"满2周岁"口径形成严重度反向分层假说——极早产但全程AGA无并发症 vs 晚期早产伴SGA/并发症，两者观察窗孰长孰短需更多案例验证，**实务线索，需人工核保确认**。

**检索方向（待 A/B 级来源）**：慕再 MIRA/瑞再 Life Guide 儿童保险（juvenile/child）早产儿/低出生体重儿（premature/low birth weight）评点页；LIA 核保指南儿童核保章节；国内再保（中再/瑞再中国）婴幼儿投保年龄与体重门槛指导；《儿童保健》相关发育评估标准（儿心-II 量表发育商分级）。

**计数器**：早产儿核保 = **4**（第 2 例：黄*玥案 11-11，双胎小宝——同一双胎、围产背景一致，但小宝状态更优：脑电图正常 / 发育商 88 全维度中等无单项临界 / PLT 346 正常 / 无尿半乳糖阳性 / 无 SGA，为"早产+低体重"双因素〔无 SGA〕形态，较首例"早产+SGA+低体重"三重因素低一档，宽松档观察窗可前移至满 1 周岁；第 3 例：青岛QD1案 11-11，孕30+6周极早产AGA双胎——NICU 39天+新生儿肺炎治愈+疑似先天性肺发育不良〔诊断待核实〕+腹股沟疝2×2cm未处理，追赶生长良好；第 4 例：青岛QD2案 11-11，孕36+6周晚期早产SGA 2235g双胎——新生儿肺炎治愈+高胆红素血症光疗史〔无胆红素脑病证据〕+母亲地贫史〔婴儿血常规未查〕，追赶生长良好）；PFO 未闭合 = 2（第 2 例：小宝 1.8mm 未复查）；语言单项临界偏低 = 1（首例，仅大宝）；腹股沟疝 = 1（首例，QD1，局灶可除外但建议手术修复后投保）；疑似先天性肺发育不良 = 1（首例，QD1，诊断必须核实——确诊触发法定除外第9项先天性畸形肺部除外）；新生儿高胆红素血症光疗史 = 1（首例，QD2，与ABO溶血病案口径一致）；母亲地贫筛查缺口 = 1（首例，QD2，婴儿自身Hb/MCV/MCH为闭环关键）。

## CL-61：子宫肌瘤术后复发＋"细胞丰富型平滑肌瘤"病理亚型口径缺口——复发轨迹与病理变异无条目（截至 2026-11）

**登记背景**：赵某婷案（11-11，31岁女）。仁济医院2024-07单孔腹腔镜子宫病损切除术（+右侧输卵管系膜病损切除），病理"平滑肌瘤伴细胞丰富"（OCR存疑，正式病理未见）；术后2年余（约2026-09）妇科彩超示**子宫多发性肌瘤复发**（多个低回声区，大者15×12mm，边界尚清，周边点状血流），仍<5cm。出院诊断合并甲状腺功能减退症（现甲功5项正常，用药状态缺位）。

**缺口确认**：引擎oncology §3良性肿瘤正档子宫肌瘤仅两档——"（<5cm，无症状，未手术）→0 标准体"与"（已手术切除）→0 标准体"。**"已手术"档隐含"无复发"假设**：本案术后2年复发多发肌瘤，两档均不适配（未手术档≠术后状态；已手术档≠有复发）；**术后复发间隔、复发数量/大小、增长速率**三变量无落档。病理亚型"细胞丰富型平滑肌瘤（cellular leiomyoma）"（良性变异，但富于细胞需与平滑肌肉瘤鉴别诊断史）全库0命中。王某凤案（11-09）"肌瘤快速增长"计数器为未手术端；本案为**术后复发端**首例，两形态分立。

**实务口径（单案观察，待多案验证；具名评点数值无 A/B 级来源，标"实务线索，需人工核保确认"）**：
1. **术后复发<5cm＋无症状＋贫血已复常** → 重疾 0~+25（标体~除外子宫）、医疗险除外子宫相关；复发不推翻"已手术良性"基础档，但**取消"术后即标体"的免检待遇**——复发者需妇科超声随访在案；
2. **复发间隔为分层变量**：≤2年复发（本案）提示复发倾向，除外倾向上调；>3年复发按新发肌瘤口径（<5cm→0/除外）；
3. **增长速率沿用**：任一时点达5cm → 06矩阵"拒保或延期"档（C级线索）；
4. **细胞丰富型亚型**：需正式病理报告确认（排除"富于细胞伴核分裂象增多"等交界表述）；纯细胞丰富型（无坏死/无异型/核分裂少）按良性处理，但核保照会应索取正式病理；
5. **共病接口**：乳腺结节+子宫肌瘤共病（组合#8）叠加术后复发形态 → 医疗险除外项数累积（LR-09≤3项审慎线），本案除外项超限形态（4-5项候选）为**首例**——除外项超限时实务以"除外主导2-3项+其余加费"或保守处理。

**检索方向（待 A/B 级来源）**：WHO子宫平滑肌肿瘤分类（2020/第5版）细胞丰富型/核分裂活跃型/不典型平滑肌瘤的良性边界标准；慕再MIRA/瑞再Life Guide妇科良性肿瘤术后复发评点条目；《子宫肌瘤诊治中国专家共识》复发率与复发间隔数据。

**计数器**：子宫肌瘤术后复发 = 1（首例，与王某凤案"未手术端快速增长"分立）；细胞丰富型平滑肌瘤病理亚型 = 1（首例）；除外项数超限形态（>3项）= 1（首例）。
