# 报价单逻辑提取规范（基线：企业团体保险自动核保报价单 v1.2）

> 每次评估都须重新委派 sheet-agent 按本清单提取；版本号不同时先 diff 结构再增量提取。以下为 v1.2 基线内容，供提取结果比对与缺口补查。
>
> **内置引擎**：本 skill 的 `assets/企业团体保险自动核保报价单_v1.2.xlsx` 即该基线的完整工作簿（4 sheet + 全部公式，锚点校验通过）。用户未提供报价单时直接用它；引擎实测规程见 §8。

## 1. Sheet 结构

| Sheet | 用途 |
|---|---|
| 01_报价单 | 输入区（客户结构/方案参数/报价参数三段，黄色格）→ 险种明细自动算价 → 赔付判断与出单判定 |
| 02_费率表A | 团体补充医疗六项责任备案费率 + 顶部"本单查表结果"区（四价加权） |
| 03_费率表B | 附加险备案费率（意外身故/伤残、意外医疗、重疾逐岁表、住院津贴、团体护理、女性生育） |
| 04_说明 | 使用说明、口径定义、已知限制、版本变更记录 |

## 2. 补充医疗六项责任（02页，元/人/年）

1. **基本医保金**（必选）：统筹起付线以上至统筹限额的个人自付，年龄×性别
2. **小额医疗**（可选）：统筹起付线以下，年龄×性别
3. **大额医疗**（可选）：统筹限额以上至大额互助限额，年龄×性别
4. **超大额医疗**（可选）：大额限额以上至40万，仅赔付比例轴（无年龄轴）
5. **小额门（急）诊**（可选）：门诊起付线以下、免赔额以上，年龄×免赔额档(50/200/500/1000)×性别×门诊独立比例系数
6. **大额门（急）诊**（可选）：门诊起付线以上至费用限额，年龄×赔付比例**直接查价**（不乘系数）

年龄轴：在职8档（≤30/31-35/36-40/41-45/46-50/51-55/56-60/61+），退休8档（≤50…81-85封顶）；在职/退休按社保状态判断。

### 比例系数表（v1.2 实测值）

**住院三项共用**（50%/60%/70%/80%/90%/95%/100%）：
0.56 / 0.71 / 0.86 / **1.00（基准）** / 1.15 / 1.25 / 1.35

**小额门诊独立系数**（无95%档，两套不能混用）：
- 在职（50%→60%→70%→80%→90%→100%）：0.35 / 0.45 / 0.56 / 0.68 / 0.80 / 1.00
- 退休：0.36 / 0.47 / 0.58 / 0.70 / 0.85 / 1.00

## 3. 输入区参数映射（询价单 → 报价单）

| 询价单字段 | 报价单输入 | 换算规则 |
|---|---|---|
| 投保人数 | F5 | 直接取 |
| 职业类别 | C6 | 1-4类；附加险职业因子：意外身故 VLOOKUP（1类1.0/2类1.32/3类1.75/4类3.0），意外医疗 CHOOSE(1/1.25/1.5/2.25) |
| 平均年龄 | C7 在职年龄档 | 均值落入哪档取哪档；跨档人群须提示按实际分布精算 |
| 男女比例 | C8 女性占比 | 男:女=a:b → 女性占比=b/(a+b) |
| 退休比例 | F8 | 不填=0 |
| 社保情况 | （约束） | 无社保客户意外医疗×24/19（公式未自动处理） |
| 住院赔付比例 | C12 | 查住院三项系数 |
| 门诊免赔额 | F12 | 查小额门急诊二维表 |
| 上年赔付率 | C20 | 驱动偏离系数 |
| 新单/续保 | F20 | 偏离系数开关 |
| 人均赔付成本 | C21 | 默认1,688元（大团体校准值，小团体仅作上限参考） |
| 费用率 | F21 | 默认19.3% |
| 目标毛利率 | C22 | 默认10% |
| 商务调整 | F22 | 只折补充医疗六项，附加险不打折 |

## 4. 保费计算公式

- **明细行通式**：`=IF(口径="‰", 人数×计价基数×基准单价/1000×风险系数, 人数×计价基数×基准单价×风险系数)×选投开关`
- **四价加权**：`（1−退休占比）×[（1−女性占比）×在职男＋女性占比×在职女]＋退休占比×[同性别加权]`
- **住院三项**：备案费率×赔付比例系数
- **意外医疗单价**：`19+MAX(0,(保额−2000)/1000)×1.62`（有社保1类0免赔；每增1000元加1.62元；无社保首2000元24元、每千加2.04元）
- **意外身故**：15元/万元保额×职业因子（1类1.5‰）
- **生育**：`2×女性占比×[有社保女性占比×S1+(1−有社保女性占比)×S2]×赔付比例`（摊全员）

## 5. 赔付判断判定链（01页）

```
偏离系数     = 新单→1；续保→上年赔付率÷80.4%   （80.4%=1,688÷2,100口径）
预期赔付     = 人数×人均赔付成本×偏离系数
保本赔付率   = 1−费用率                        （19.3%=佣金12%+保障基金0.8%+人力4.2%+理赔1.5%+系统0.8%）
保本保费     = 预期赔付÷(1−费用率)
建议报价     = 保本保费×(1+目标毛利)+附加险保费
调整后赔付率 = 预期赔付÷调整后补充医疗保费
出单判定     = ≤0.8"通过"；0.8-0.9"需审批"；>0.9"不建议"
```

判定只对补充医疗六项做；附加险按备案价不参与。

## 6. 已知限制（评估时必须逐条对照）

1. 重疾/津贴/护理退休人员按在职档计价（含大量退休时偏低）
2. 补充医疗无职业因子
3. 退休档81-85封顶，超龄按最高档
4. 意外医疗按有社保价，无社保×24/19（公式未自动处理）
5. 备案费率未标基准保额，按1:1处理
6. **赔付判断把备案价与"人均2,100/赔付1,688"口径直接对比，保额未必一致——赔付率偏高先查保额差，勿直接认定定价不足**

## 7. sheet-agent 提取清单（每次评估照单全收）

1. 全部 sheet 清单（名称+用途+行列规模）
2. 费率表结构：年龄轴、责任分项、计价维度
3. 与本单相关的具体费率数值（按询价单的年龄档/免赔档/赔付比例取数，男女都要，附单元格地址）
4. 比例系数表全量数值（确认档位存在性）
5. 输入区/参数区字段与联动链路
6. 公式原文（明细行、加权、偏离、判定）
7. 04页已知限制与版本变更记录
8. 表内是否已含本案客户数据（全文检索）

## 8. 引擎实测规程（用报价单本身算价与判定）

**前提**：把 `assets/企业团体保险自动核保报价单_v1.2.xlsx`（或用户报价单）复制到工作区（如 `output/<id>/engine.xlsx`），所有写操作只在副本上。

**填写输入区**（委派 sheet-agent 执行，01页黄色格，按 §3 映射表换算）：

| 格 | 字段 | 填写要求 |
|---|---|---|
| C5 | 投保单位 | 询价单客户名（纯文本） |
| F5 | 投保人数 | 整数 |
| C6 | 职业类别 | "1类"~"4类" 文本格式 |
| C7 | 在职年龄档 | 均值所在档（"41-45"格式） |
| F7 | 退休年龄档 | 无退休可不填 |
| C8 | 女性占比 | 小数（男:女=2:1→0.3333） |
| F8 | 退休占比 | 无退休=0 |
| C12/F12 | 住院赔付比例 / 门诊免赔额 | 必须取系数表存在的档位（住院 50/60/70/80/90/95/100%；免赔 50/200/500/1000） |
| C13-F17 | 各附加险保额/开关 | 未投险种开关 A26:A37 置 0 |
| C20/F20 | 上年赔付率 / 新单续保 | 续保才填赔付率 |
| C21 | 人均赔付成本 | 默认1,688（大团体校准值，小团体作上限参考） |
| F21 | 费用率 | 默认0.193；直销口径可改0.073 |
| C22/F22 | 目标毛利 / 商务调整 | 按案设定 |

**⚠️ 输入区默认是示例案例**（500人物业公司：41-45档/40%女性/80%住院比例/95%上年赔付率等），实测时**必须全部覆写**为本案参数再读数，漏改任何一格都会污染结果。

**读回结果**（01页）：
- H26:H37 险种明细保费、H38 补充医疗六项小计、H39 合计、H40 人均保费
- C44 附加险保费、C45 偏离系数、C46 预期赔付、C48 保本保费、C49 建议报价、C51 调整后保费、C52 调整后赔付率、C57 出单判定
- 02页顶部"本单查表结果"区 B6:F16 各责任加权单价（复核费率重现用）

**局限与双轨校验**：
- 非整档赔付比例（如85%）工作簿无对应档：先按相邻档（80%/90%）引擎实测，再手工插值，报告标注"插值近似"
- 住院产品若为费用型全额补偿口径（如福泰10万0免赔），六项分段责任引擎值与产品标准保费口径不可比（限制⑥）——引擎值照出，比对结论写"口径不可比，需人工核对构成"，不得硬判标准保费异常
- 引擎值与手工重现值并行呈现，互相校验；不一致时先查输入区是否漏改示例值
