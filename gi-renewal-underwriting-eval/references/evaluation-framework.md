# 核保评估框架（多情形判定与量化验证）

## 1. 赔付经验整理规则

- 按**保单年度**整理（非日历年），逐年列出：医疗保费、医疗赔款、赔付率，拆门诊/住院。
- **成熟度判定**：到期≥12个月视为基本成熟；未到期或刚到期的"0%赔付率"标记"未成熟"，**不作定价依据**。
- 意外险与医疗险分开统计；综合赔付率（含意外）与医疗险赔付率并列呈现。
- 剔除险种混入（如交通工具、津贴）后再算医疗口径。

## 2. 多情形判定矩阵（每案必做，六情形）

以医疗报价（申请价×人数）为分母，按报价单判定规则（≤80%通过 / 80-90%需审批 / >90%不建议）：

| 情形 | 经验基准 | 算法 |
|---|---|---|
| 乐观 | 最近成熟年度综合赔付率 | 报价单判定链：偏离系数=赔付率÷80.4%→人数×人均成本×偏离 |
| 客户经验-乐观 | 最近成熟年度 | 客户自身人均赔款×人数÷医疗报价 |
| 中性 | 两个成熟年度保费加权 | 加权赔付率×报价（或客户经验均值） |
| 客户经验-中性 | 两年度人均赔款均值 | 同上 |
| 悲观 | 最差年度（通常为核保意见采用口径） | 判定链 / 客户人均，双口径都算 |
| 客户经验-悲观 | 最差年度人均赔款 | 同上 |

**判定结论读法**：
- 六情形横跨"通过~不建议"是**小团体经验可信度不足的直接量化表现**，报告必须点明；
- 中枢判断取"两年客户经验均值 + 最差年客户经验"的区间；
- 人数<25时声明"报价单大数法则假设失效"，1,688人均成本口径仅作上限参考。

### 保本测算（三行表）

保本保费=预期赔款÷(1−费用率)，分别以最差年/两年均值/最近成熟年赔款计算，与报价对比给出缺口（费差倒挂/盈余%）。

## 3. 修改方案量化验证（双向分析，防"联动抵消"陷阱）

对每个拟修改项同时算**赔款端**与**保费端**：

### 赔付比例下调（如90%→85%）

- 赔款端：预期赔款×(新比例/旧比例)（就医行为不变假设）；若比例档在系数表中不存在（如85%），插值并标注。
- 保费端：标准保费按备案系数联动（住院查共用系数表、门诊小额查独立系数/大额直接查价），得出各险种降幅。
- **联动抵消效应（关键洞察）**：若客户要求按标准保费降幅同步降价，赔付率=赔款降幅÷保费降幅——赔款降5.56%而保费降6.5-8.9%时**赔付率不降反升2-4个百分点**。核保意见必须写明"比例降至X%，报价维持不降"，否则改善被完全抵消。

### 免赔额/保额调整

同一框架：赔款端（自付吸收效应）vs 保费端（备案费率轴变动）。

### 保费演变背景

拉通3年人均保费演变（如500→900→1050），识别"高赔付后大幅提价"与"提价后持平"两种续保形态——持平报价要判断是"提价后首轮持平"（合理）还是"连续未调"（需复核）。

## 4. 特别约定风险评估（风险等级排序）

| 风险模式 | 识别要点 | 通常等级 |
|---|---|---|
| **取消住院天数限制** | 单人赔款上限 vs 住院保费池杠杆（本案9万vs4500元=20倍）；查既往住院赔付率是否已实证单案冲击 | 高 |
| **承担既往症+取消观察期** | 存量连续投保风险可控；风险在**增员环节**——与"增员免手续费+便捷保全通道"叠加形成逆选择通道 | 中-高 |
| 流程性约定（邮件保全、免手续费） | 纯操作便利 | 低 |

配套建议动作：新增人员恢复疾病观察期、健康告知（重疾定义清单口径）、超天数住院单独设限额。

## 5. 核对发现清单（逐项过，命中才写）

1. **折扣合规**：附加险是否违反"只折补充医疗、附加险不打折"原则；结合职业类别+历史零赔付判断可否例外接受。
2. **表外费率**：报价单费率表缺位的险种（如交通工具），要求渠道提供备案出处。
3. **费用率口径矛盾**：方案表所填手续费/佣金 vs 备注"直销不涉及"——两口径下保本赔付率差异（19.3%费用率→80.7% vs 直销7.3%→92.7%）直接翻转盈亏判定，签报必须明确。
4. **年龄结构跨档**：仅给均值时按档取价，跨档人群须索取人员清单按实际档精算。
5. **意外险经验**：多年零赔付的意外险打折可例外接受，但小池身故敞口（保额×人数 vs 保费池）要提示。

## 6. 分层结论模板

| 层级 | 内容口径 |
|---|---|
| 报价充足性 | 对最近成熟年/最差年的盈余或缺口%+标准保费核对归类 |
| 赔付率判定 | 中枢区间+所属判定区间+"不建议"仅出现在哪个情形 |
| 结构性风险 | 人数分散能力+折扣最深险种与最差经验险种的错配+责任扩展约定 |
| 综合判定 | 通过/需审批/不建议+是否条件承保 |

**条件承保建议清单**（按案裁剪）：比例调整+报价维持条款、新增人员健康告知+观察期、超天数限制单独设限、口径核实三件套（费用渠道/表外费率/年龄分布）、**中期理赔监控触发线（如上半年医疗赔付率超80%触发费率回顾）**、扩员至25人以上恢复大数法则。
