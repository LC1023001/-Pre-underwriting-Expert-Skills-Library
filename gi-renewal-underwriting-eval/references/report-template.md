# 评估报告模板与 DOCX 产出管线

## 1. 报告 8 章结构（内容稿 md 按此组织）

```
# <客户名><年度><产品线>续保/新保件 核保评估报告

元信息块：评估依据 / 评估对象（报价编号）/ 评估人 / 日期

## 摘要（执行摘要）
- 综合判定 + 中枢区间一句话
- 三项关键发现（每项带量化数字）

## 一、案件概览                    —— 要素表（业务性质/人员结构/生效日/保费规模/健康申报/待批核心）
## 二、方案与报价结构核对          —— vs 上年在保逐险种表 + 修改方案实质 + 保费演变背景
## 三、备案费率核对                —— 重现值/标准保费/偏差/结论四列表 + 重现计算明细 + 要点
## 四、赔付经验与多情形判定        —— 经验表 + 六情形表 + 判定结论 + 保本测算表
## 五、修改方案量化验证            —— 赔款端/保费端 + 联动抵消警示块 + 调整后参数参考
## 六、特别约定风险评估            —— 序号/约定/评估/等级四列表
## 七、其他核对发现                —— 有序列表（命中核对清单的项）
## 八、分层结论与核保建议          —— 四层结论表 + 建议有序列表 + 尾注（口径与近似声明）
```

## 2. 写作纪律

- 所有数字可追溯到询价单、引擎实测结果（quotation-logic.md §8）或算式；插值近似必须标注。
- 结论分层呈现，每条结论跟随量化证据。
- 警示块节制：全文 ≤3 个（联动抵消效应、最高风险特别约定、执行摘要卡）。
- 尾注声明测算口径（人均成本默认值适用性、插值项、统计日与理赔滞后）。

## 3. DOCX 产出管线（organize 模式）

1. 内容稿落 `stage1/organized_draft.md`；
2. 走 `workbuddy-docx` skill → expand_writing → organize 分支：自产 HTML（业务报告体裁：封面节 + 目录节 + 正文节；宋体正文 ≥12pt、黑体标题、text-indent 2em；表格全带 thead/tbody；`@page` 页脚页码 + 封面无家具；CSS 变量无裸值）；
3. 过 HTML 质量门禁（review_html.py --genre business-report），不过则修正一次复检一次；
4. convert_doc.py 转换 → present_files 成品；
5. 交付说明在对话中给结论摘要（分层判定+关键数字+报告路径）。

## 4. 实战基线案例（2026-11-18 中科*讯，供风格与深度参照）

10人直销续保件（1类职业、均值43岁、男女2:1、2027福康福泰），核心产出：
- 费率重现：意外险150元完全一致、门急诊重现1,193.07 vs 标准1,394.96（含17%边际）、住院无法用六项责任重现（限制⑥实证）
- 六情形：47.5%~203.1%横跨三个判定区 → "需审批+条件承保"
- 85%比例建议：联动调价抵消效应（赔付率反升2-4pct）→ 意见须绑定"报价维持不降"
- 最大尾部风险：取消180天住院限制（9万敞口 vs 4,500元住院保费池，20倍杠杆）
- 中期监控：上半年医疗赔付率>80%触发费率回顾
