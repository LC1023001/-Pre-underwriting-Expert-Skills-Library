# 中医体质辨识与治未病健康方案

本技能基于**《中医体质分类与判定》国家标准（GB/T 46939-2025）**（2026年4月1日正式实施），由北京中医药大学国家中医体质与治未病研究院王琦院士团队制定，提供完整的体质辨识和个性化养生方案生成服务。

## 功能概述

1. **中医体质问卷引导** - 通过标准化问卷收集用户体质信息（支持54题完整版和30题简化版）
2. **体质类型判定** - 根据国家标准计算九种体质倾向分数
3. **健康风险评估** - 基于体质类型分析潜在健康风险
4. **治未病干预方案** - 生成涵盖饮食、运动、情志、起居等多维度的个性化养生方案

## 九种体质分类

根据国家标准，人体分为九种体质类型：

| 体质类型 | 核心特征 | 倾向人群 |
|---------|---------|---------|
| 平和质 | 阴阳气血调和，体态适中，面色润泽，目光有神，精力充沛 | 健康人群 |
| 气虚质 | 元气不足，疲乏、气短、自汗 | 体质虚弱者 |
| 阳虚质 | 阳气不足，畏寒怕冷、手足不温 | 虚寒体质者 |
| 阴虚质 | 阴液亏少，口燥咽干、手足心热 | 热性体质者 |
| 痰湿质 | 痰湿凝聚，体形肥胖、腹部肥满、口黏苔腻 | 肥胖人群 |
| 湿热质 | 湿热内蕴，面垢油光、口苦、苔黄腻 | 湿热体质者 |
| 血瘀质 | 血行不畅，肤色晦黯、舌质紫黯 | 循环障碍者 |
| 气郁质 | 气机郁滞，神情抑郁、忧虑脆弱 | 情志不畅者 |
| 特禀质 | 先天失常，以生理缺陷、过敏反应为主 | 过敏体质者 |

**标准来源：** GB/T 46939-2025《中医体质分类与判定》，由国家市场监督管理总局、国家标准化管理委员会发布，2026年4月1日正式实施。

## 工作流程

### 第一步：收集基本信息

询问用户的以下基本信息：

- 姓名（可选）
- 性别
- 年龄
- 既往病史（如有）
- 主要健康诉求

### 第二步：执行体质问卷

引导用户回答中医体质分类与判定问卷。提供两种版本供选择：

**版本A：54题完整版**（精确度高，适合全面评估）
**版本B：30题简化版（CCMQ-30）**（快速便捷，适合初步筛查）

**原始分计算方法：**
- 原始分数 = 各条目分值相加
- 转化分数 =（原始分 - 题数）× 100 / (题数 × 4)

**判定标准：**
- 平和质：转化分≥60分，且其他8种体质转化分均<40分 → 是
- 平和质：转化分≥60分，且其他8种体质转化分均<30分 → 基本是
- 偏颇体质：转化分数 ≥ 40% → 是
- 偏颇体质：转化分数 30%-39% → 倾向是
- 偏颇体质：转化分数 < 30% → 否

### 第三步：体质判定与报告生成

根据问卷结果，计算各体质转化分数，判定体质类型并输出完整报告。

## 输出报告结构

### 1. 体质辨识结论

报告应包含：

- **主要体质：** [体质类型]
- **体质特征：** [简要描述]
- **转化分数：** XX%
- **兼夹体质：** [如有，列出其他偏高体质]

### 2. 健康风险评估

- **高风险领域：** 基于体质类型分析易患疾病
- **中风险领域：** 潜在健康问题
- **低风险领域：** 体质优势

### 3. 治未病干预方案

#### 3.1 饮食调理

- **饮食原则：** 总体饮食建议
- **推荐食材：** 具体食材列表
- **禁忌食材：** 应避免的食物
- **药膳推荐：** 1-2个药膳方

#### 3.2 运动养生

- **运动原则：** 适合的运动类型
- **推荐项目：** 具体运动建议
- **运动强度：** 建议强度和时长
- **注意事项：** 运动禁忌

#### 3.3 情志调节

- **情志特点：** 体质对应的情志特征
- **调节方法：** 具体情志调理建议
- **推荐活动：** 有益的情志活动

#### 3.4 起居调养

- **环境要求：** 适宜的生活环境
- **作息建议：** 睡眠和作息建议
- **四时养生：** 季节性调养重点

#### 3.5 中医特色疗法

- **推拿/艾灸穴位：** 具体穴位建议
- **中药调理：** 基础调理建议
- **其他疗法：** 拔罐、刮痧等

#### 3.6 四季养生指导

针对不同季节提供专项调养建议。

## 问卷题目

### 版本A：54题完整版

#### 一、平和质（6题）

1. 精力充沛，不易疲劳
2. 睡眠良好，入睡快、醒后精神足
3. 食欲正常，三餐规律且进食量稳定
4. 面色红润，有光泽
5. 大小便规律，无异常不适
6. 对外界环境适应能力强（如冷热、湿度变化）

#### 二、阳虚质（6题）

7. 平时怕冷，手脚冰凉（尤其冬季或接触冷水后）
8. 吃生冷食物后易腹泻、腹痛
9. 精神不振，容易犯困，缺乏活力
10. 面色苍白或偏白，无光泽
11. 穿衣服比同龄人多，仍觉不暖和
12. 夜间排尿次数多（起夜2次及以上）

#### 三、阴虚质（6题）

13. 经常口干舌燥，喝水后仍难缓解
14. 手脚心发热，夜间睡觉时更明显
15. 夜间易盗汗（睡时出汗，醒后汗止）
16. 大便干结，排便费力
17. 眼睛干涩，视物久后易疲劳
18. 舌红少津（舌头偏红，舌苔少或无苔）

#### 四、气虚质（6题）

19. 稍微活动就容易疲劳、气短
20. 说话声音低弱，不爱说话
21. 容易感冒，感冒后恢复时间长
22. 站立或蹲坐后起身时，容易头晕
23. 精神不振，注意力难以集中
24. 活动后易出汗（非剧烈运动情况下）

#### 五、痰湿质（6题）

25. 体型偏胖，腹部松软肥胖
26. 面部油脂多，容易出油、长痘
27. 平时痰多（白色稀痰或黏痰），喉咙总觉有异物
28. 身体沉重，活动后易困倦、乏力
29. 大便黏滞不爽（排便后马桶难冲净）
30. 舌体胖大，舌苔白腻

#### 六、湿热质（6题）

31. 面部、胸背部易长痘，且痘痘红肿疼痛
32. 口苦、口中黏腻，偶尔有口臭
33. 小便颜色深黄（如浓茶色）
34. 大便黏滞，或排便时肛门有灼热感
35. 皮肤易瘙痒（如湿疹、皮炎反复发作）
36. 舌红，舌苔黄腻

#### 七、血瘀质（6题）

37. 面部、嘴唇颜色偏暗，或有黑眼圈
38. 身体容易出现瘀斑（碰撞后青紫难消退）
39. 女性月经颜色暗，有血块，或痛经明显
40. 偶尔有头痛、胸痛，疼痛性质为刺痛（固定部位）
41. 舌质偏暗，或有瘀点、瘀斑
42. 皮肤干燥，缺乏光泽

#### 八、气郁质（6题）

43. 情绪容易低落，经常感到不开心
44. 爱思虑，容易焦虑、紧张，睡眠质量差
45. 遇到小事就容易生气，或情绪波动大
46. 对生活兴趣不高，缺乏动力
47. 胸闷、胁肋部偶尔胀痛（两侧肋骨下方）
48. 说话声音小，不爱与人交流

#### 九、特禀质（6题）

49. 容易过敏（如花粉、尘螨、食物、药物过敏）
50. 皮肤容易起荨麻疹（风团、瘙痒）
51. 换季时易打喷嚏、流鼻涕（非感冒引起）
52. 对特定气味、温度变化敏感（如香水、冷空气）
53. 小时候容易患湿疹、哮喘，或家族中有过敏史
54. 您的皮肤一抓就红，并出现抓痕吗？

**评分标准：** 每题按1-5分评分
- 1分：没有（根本不）
- 2分：很少（有一点）
- 3分：有时（有些）
- 4分：经常（相当）
- 5分：总是（非常）

## 注意事项

1. **体质转化**：体质不是一成不变的，通过正确调养可以改善
2. **兼夹体质**：多数人属于兼夹体质，需要综合调理
3. **专业建议**：复杂健康问题建议咨询专业中医师
4. **因人制宜**：方案需根据个体实际情况灵活调整
5. **年龄因素**：儿童、老年人、孕妇等特殊人群的体质判定标准有所不同
