# 知识库巡检线索登记簿（kb-clues）——C/D 级线索层，升级不覆盖

> 依据 LR-01：C/D 级来源**不得作为核保判断依据**，仅作检索线索与方向提示。
> 本文件登记各轮知识库巡检中获得的 C/D 级方向性线索，供后续定向深挖定位 A/B 级原始来源。
> 每条线索必须带"截至 YYYY-MM"标注，过期即失效；**任何条目不得进入评估报告依据表**。

## CL-01：心律失常（室早/房早）核保方向线索（截至 2026-10）

**登记背景**：2026-10-15/10-16 两案形成"偶发 vs 频发/二联律"分水岭对照，具名 A/B 级档位仍缺（深挖队列第 2 位）。

**C 级来源方向观察**（美/英经纪平台多源一致，媒体互转风险仍在，不构成互证升级）：
- 室早（PVC）/房早（PAC）**无器质性心脏病、无症状** → 多数载体"not rated"（不加费），可控药物替代治疗 → 标准费率附近；
- PVC/PAC 为"常见、多为良性异位搏动"，结构性心脏正常时不显著影响死亡率——与 LR-05 方法论的功能性早搏定性路径方向一致；
- 持续性心律失常（房颤/室速/WPW）显著区别于早搏，核保 scrutinize 程度不同；房颤单次发作+高龄+控制良好可争取标准，多次发作→次标准；
- 消融成功（恢复窦律+无抗心律失常药+随访监测阴性，通常 30 天事件记录仪或复查 Holter）→ 优于长期药物控制路径；
- 未完成 EKG/Holter 等检查的心律失常申请 → 常见 postponement（延期）——与 10-16 案"资料缺口型延期"结论方向一致。

**来源**：heartlifeinsurance.com / careproinsurance.com / over50lifeinsure.com / iaminsured.co.uk（均为 C 级经纪平台）+ 深蓝保问答（C，LR-02 已列降级清单）
**用途**：仅提示"国际市场对无器质性早搏普遍不加费"的方向，**待 LIA/再保手册 A/B 级档位取回后方可作为依据**。

## CL-02：结肠腺瘤/息肉核保方向线索（截至 2026-10）

**登记背景**：2026-10-20 乙结肠腺瘤案（UW-20261020-LXY）+ 10-09 Barrett 案，消化系统癌前病变具名 A/B 级档位缺（深挖队列第 1 位，3 案累积）。

**C 级来源方向观察**（美/英经纪平台）：
- 良性息肉已切除 + 监测肠镜阴性 + 维持监测节奏 → "标准或接近标准费率"；切除后建议**至少 6 个月**再申请（恢复期内的申请可能 postponement）——与本案"切除后 6-12 个月复查肠镜阴性"复议路径方向一致；
- 评估要素：息肉病理类型（增生性/腺瘤性/进展期）、个数、高级别异型增生、监测依从性、伴随疾病；
- 进展期病理（高级别异型增生）/反复复发/监测中断 → table rating（美式每档约+25%）或延期；
- 息肉未切除 → 通常拒保或延期至切除。

**B 级边缘来源（时效存疑，暂列线索）**：Munich Re 专家（Hélène Michaud/Joan Tolan）在 Advisor.ca 刊载的癌症家族史核保文章（**2009 年**）——结肠癌家族史评点 +50、结肠镜阴性可抵减 25 分（净 +25）。年份久远且为期刊转述，按 LR-01 从严暂列线索，待 Munich Re 正式手册原文核实。

**来源**：insurancebyheroes.com / over50lifeinsure.com（C 级经纪平台）；advisor.ca Munich Re 撰文（B 级边缘，2009）
**用途**：确认"切除+阴性监测→标准体方向"的国际市场共识方向，待再保手册 A/B 级分层档位取回。

## CL-04：RA + 桥本等自身免疫组合核保方向线索（截至 2026-10）

**登记背景**：2026-10-13 RA+桥本案登记共病组合缺口（18 组之外候选第 19 组）。

**C 级来源方向观察**（英美经纪平台多源方向一致）：
- 桥本甲状腺炎：** levothyroxine 替代治疗 TSH 稳定（2 年+）→ "标准费率"为多平台一致表述**；未控制/反复调药 → Table 2-4 或延期至稳定——与 10-10 案"甲减复议证据链（小剂量+TSH达标连续记录）"方向一致；
- RA：分严重度——轻度/控制良好（稳定 2 年+、无器官受累、无住院）→ 标准~Table 2；中重度（发作频繁/器官受累/住院史）→ Table 4~拒保；**生物制剂（ biologics）治疗为显著核保因子**——与 10-13 案（乌帕替尼 JAK 抑制剂初治→延期）方向一致；
- 自身免疫病通用评估变量：疾病活动度、器官受累、治疗层级（DMARDs/生物制剂/激素）、距末次发作时间——"控制年限+器官受累"双维度框架与 LIA 器官波及原则可对接。

**B 级边缘来源（载体受限，暂列线索）**：AIG 外勤核保指南 PDF（mbwinsurance.com 经纪网站托管）——**Hashimoto's Disease 列"Not Rated"（不加费档）**；GBS（吉兰-巴雷）列有评点档。原始出处为 AIG 官方指南但经经纪网站转载，按 LR-01 从严暂列 C 级，待 AIG 官方原始链接核证后可升 B。

**来源**：simpleprotection.co.uk / lifequotesweb.com / insurancebyheroes.com / lifequote.com（C 级经纪平台）；AIG Field Underwriting Guide（C 级暂列，载体待核）
**用途**：RA+桥本组合的"分别评估、控制年限分档"方向确认，待 A/B 级来源取回后设计第 19 组共病组合规则。

## CL-07：儿童热性惊厥/癫痫核保规则缺口（截至 2026-10）

**登记背景**：2026-10-21 首次遇到热性惊厥史儿童个案（6岁女童，2024年住院，24h内2次发作共约10min，疑诊"癫痫持续状态？"未确诊，无EEG记录，无复发2年8个月）。

**缺口确认**：uw-knowledge-base 检索"惊厥/热性惊厥/癫痫/高热惊厥"均 0 命中，基线未覆盖儿童惊厥类疾病。

**检索方向（待 A/B 级来源）**：LIA 核保教材儿童疾病章节；再保手册 pediatric convulsion rating page（付费制）；国内行业协会儿科核保指引。

**实务要点沉淀**：①"癫痫持续状态？"等鉴别疑问表述未确诊仍触发人工核保；②复杂型（24h内≥2次）与单纯型区分影响结论区间；③补充正常 EEG 是结论上移最有效动作；④无复发满2年＋年龄>5岁为有利窗口。

**用途**：同类个案按本条方向推导，数值/档位结论一律标注"实务线索，需人工核保确认"。

## CL-08：乙肝活动性肝损复常后核保时间窗缺口（截至 2026-10）

**登记背景**：2026-10-21 钱某案（UW-20261021-QDD，38岁女性，大三阳三年持续 + 2026-03 急性肝损 ALT 569/AST 403 + 2026-04-08 复查复常）。

**缺口确认**：uw-knowledge-base 无"乙肝急性发作/肝功异常后复常满 N 个月可恢复人工核保"时间窗条目；05 矩阵仅有"携带（肝功正常）→可标准"与"肝功异常→除外/防癌险"两端状态，**无发作后恢复路径**。

**实务方向观察（C/D 级线索）**：
- 市场通行"肝功复常满 6 个月"可受理口径（10-21 案采用，D 级个案观察，配合 LR-08 双维法使用）
- 大三阳（HBeAg+）经治疗复常后，各公司引擎分支不同：走"携带（肝功正常）"路径还是仍按"乙肝+肝损史"路径评点
- 照会标准材料组：①HBV-DNA 定量（定性证据）②近 6 个月 ≥2 次连续肝功（控制证据）③肝脏超声/弹性成像（器官状态证据）④AFP
- GGT 单独轻度升高（本案 53）复常后的评点影响未观察到 A/B 级条目

**检索方向（待 A/B 级来源）**：LIA 核保指南肝病章节；再保手册 hepatitis / hepatitis B rating page（付费制）；《慢性乙型肝炎防治指南》（中华医学会感染病学分会/肝病学分会）与核保的衔接口径。

**用途**：同类个案按 LR-08 双维法 + 本条方向推导；时间窗与档位数值结论一律标注"实务线索，需人工核保确认"。

## CL-09：磨玻璃结节/持续血尿/肾结石/Lp(a) 核保条目缺口（截至 2026-10）

**登记背景**：2026-10-22 郑*娴案（UW-20261022-ZJX，35岁女性）。

**缺口确认**：uw-knowledge-base 检索"磨玻璃/Lung-RADS/血尿/尿隐血/结石/脂蛋白"仅命中零散 C 级线索，无 A/B 级专门条目：
1. **磨玻璃结节（GGN）**：05矩阵仅有"实性<8mm且稳定"条目；GGN首检无对照 vs 有稳定对照的结论分档无依据（个案已2例，10-09/10-22）
2. **持续镜下血尿/尿隐血**：伴结石归因未闭环时的核保路径（除外泌尿 vs 复查后决定）零条目
3. **肾结石**：仅有"易核版可投"C级线索，尺寸/积水/肾功能分档无条目
4. **Lp(a)升高**：零覆盖；Lp(a)伴CAC 0分的心血管核保权重无从判断

**检索方向（待 A/B 级来源）**：Swiss Re Life Guide 心血管章节（Lp(a)/CAC 联合评估，付费墙）；再保手册 hematuria / renal stone rating page；LIA 核保指南泌尿系统章节；《中国心血管病一级预防指南》Lp(a)与核保的衔接口径。

**用途**：同类个案按器官波及原则（B级）+ LR-08 双维法做方向推导，具名档位结论一律标注"实务线索，需人工核保确认"。
