# UW-20261023-JXL：34岁男性——肺微小结节（3年稳定）+HP新发+双肾结晶+尿酸临界+尿隐血±+前列腺饱满

**评估日期**：2026-10-23 ｜ 状态：预核保预估（无正式核保结果回执）

## 案情要点

男，34岁，上海，两次年度干部体检对比（2024-11-09 → 2025-10-24）：

- 右肺中叶外侧段实性微小结节 4mm → 3-4mm，**2023-11-28 → 2024-11-09 → 2025-10-24 三次CT相仿，稳定约2年**，Lung-RADS 2类。
- **C13呼气 2024阴性 → 2025阳性（DOB 5.2）**，新发HP感染；胃蛋白酶原正常（PGI 62.3、PGI/PGII 6.75），无萎缩性胃炎证据。
- 尿酸 403 → **437**（参考≤428，轻度超标）；肾结晶由**左肾 → 双肾**；**尿隐血±新发**（镜检未见红细胞）；尿微量白蛋白/肌酐/eGFR正常。
- 前列腺 51×30×28 → 46×31×30mm"增大"、回声欠均匀，**PSA 0.97正常**。
- 孤立性总胆红素 26.1（≤26压线超标），ALT 5.5↓/AST 12.7↓（偏低非升高），Hb 152正常，肝胆超声正常。
- 左第3前肋陈旧性骨折（已愈合）；迷走右锁骨下动脉（先天变异）。
- **积极改善**：BMI 26.30→23.26、血压130/83→119/77、鼻炎咽炎消失、尿白细胞酯酶转阴。

## 结论方向（预估）

- 重疾：**标准体～除外**（综合评点折叠后约+50，HP+25与尿酸/结晶代谢链+25，肺结节评点0）；医疗：除外肺部+泌尿+胃部（2-3项）；防癌险：除外肺～延期；寿险/意外/年金：标准体。
- 整体风险低～中低。最佳路径：**HP根除+尿酸管理后投保，结论可升级**。

## 规则观察（个案观察，待多案验证）

1. **"肾结晶"与"肾结石"的规则边界**：v2.7肾结石规则表按结石大小/积水/功能分档，**结晶（点状强回声无声影）未单列**。本案结晶双侧+尿酸临界+尿隐血±三者同源，按"结石+高尿酸血症+25~+50"行的低端（+25）处理。建议后续将"结晶"作为结石前态单独一行入库（评点0～+25，取决于是否合并高尿酸/尿隐血），待多案验证。
2. **HP由阴转阳的纵向动态**：新发感染+PG正常 → 风险显著低于慢性携带者；既有个案沉淀（陶*峰案）"HP阳性→转阴可移除除外因素"提示**根除治疗是核保结论升级最明确的干预路径**，本案首次遇到"反向动态"（阴→阳），评估时点敏感性高——投保前根除并复查转阴，可完全规避该项。
3. **迷走右锁骨下动脉**：包内基线无条目。先天性血管变异、无症状、无血流动力学意义，两案核保处理均为**评点0标准体**（含本案）。若再次遇到，可按"先天性解剖变异（无症状）→ 标体"待多案验证后入库。
4. **孤立性总胆红素压线超标（1.0×ULN）+ 肝酶偏低**：v2.7"孤立性胆红素轻度升高→标体"规则适用良好；本案补充特征——ALT/AST**低于**参考区间下限与胆红素升高共存时，反而强化"良性/Gilbert样"判断（肝细胞损伤方向证据缺失）。
5. **多异常条目但无单项严重的画像**：智能核保逐项均可友好处理，但多项命中问询整体转人工——此类"多而轻"案件的核保摩擦主要在**条目数量**而非单项评点，投保顺序策略（先寿险/意外，重疾/医疗待优化后投）是核心价值点。
