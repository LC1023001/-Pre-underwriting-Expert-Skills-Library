# 个案沉淀：儿童右膝皮下脉管畸形（伴静脉石）+右股骨远端纤维骨皮质缺损+髋滑膜炎已愈（2026-11-03）

## 案情摘要
- **患者**：刘某（报告可见"刘*希"），性别/出生日期**未见载明**（材料缺口），超声报告"请监护人妥善保管"提示儿科患者，按就诊时间线推断现约学龄期
- **资料**：4张微信图片——2023-10-24门诊病历（右髋痛+右膝上肿就诊）+双髋/右膝超声 + 2026-04-29膝关节MR平扫报告2页（对比2025-04-20 MR，2025年原片未提供）
- **诊断链**：
  1. **右膝前内侧皮下脉管畸形**（静脉畸形可能）：2023超声5.0×3.5×1.1cm低回声团，边界欠清、形态欠规则，内见斑片状钙化（静脉石）伴声影，稀疏点状血流；2026-04 MRI 33×7×53mm**较前略大**，T2-DIXON水相高信号+条状低信号（静脉石形成可能），**局限于皮下脂肪层**，边界清，邻近肌肉骨骼无水肿。2023-10门诊医嘱"**择期手术治疗**"，截至2026-04**无手术记录**
  2. **右股骨远端纤维骨皮质缺损**（干骺端内侧后缘骨皮质缺损14×5×14mm，边缘骨质硬化，**范围大致同前、信号较前减低**=静止/好转）
  3. 右髌上囊及膝关节腔少许积液（2026-04）
  4. 髋关节滑膜炎（2023-10初诊；当时超声双髋滑膜间隙5.8/5.7mm基本对称、无积液——实际已趋正常，3年无复发）→ **已愈**

## 核保结论（方向）
- **重疾险**：除外承保为主方向（除外脉管畸形/血管病变及相关责任）；宽松档可能仅除外血管畸形；严格档延期至治疗闭环
- **医疗险**：除外（血管畸形+骨科相关）～延期（择期手术未执行+病变增大，中等/严格档倾向延期至手术/介入后）
- **防癌险**：标准体可期（良性非肿瘤病变）
- **寿险**：标准体～除外（监管限额内：<10周岁20万/10-18周岁50万）
- **意外险**（无健康告知类）：标准体
- **风险分层**：中（无恶性信号、无系统受累 vs 未治疗缓慢进展病变+手术医嘱3年未闭环）

## 关键判断依据
1. **先天性畸形免责射程（A级）**：脉管畸形属先天性血管发育异常，落入重疾险示范条款责任免除第9项"遗传性疾病，先天性畸形、变形或染色体异常"（02-监管规范§责任免除）——即便承保，因该畸形直接导致的重疾给付本身属条款免责；核保决策核心转为"未治疗活动性病变的整体健康信号+医疗险即期费用风险"
2. **器官波及原则（B级 LIA §1.1）**：病变局限皮下脂肪层、无肌肉/骨骼/内脏受累 → "疾病不影响其他器官"情形 → 可承保+除外该疾病及关联风险；无多系统受累不触拒保逻辑
3. **医嘱手术未执行=延期触发器**：参照06矩阵"需尽快手术→拒保或延期；术后病理良性+复查无异常→标准体方向"的方法学（子宫肌瘤条目，**口径独立仅结构类比，不移植数值**）
4. FCD：儿童干骺端常见良性纤维性骨病变，多自愈，本案静止好转 → 无独立评点（实务线索）

## 观察点（新规则边界）
1. **儿童软组织脉管畸形核保首例**（登记CL-30）——出厂基线+沉淀区均无条目；分水岭=①治疗闭环状态（医嘱手术未执行是独立延期触发器，与"医嘱手术"问项直接对应）②病变演进方向（较前略大 vs 稳定/缩小）③综合征筛查（KTS等，肢体静脉畸形须排查）
2. **"择期手术"医嘱的时间衰减问题**：2023年医嘱至2026年未执行——核保上医嘱手术史不因时间流逝失效（与10-28腺样体肥大"医嘱手术未执行=风险敞口"同构），反而是"病变持续存在+家属未处置"的确认信号
3. **纤维骨皮质缺损评0路径首例**（登记CL-31）——静止/好转的FCD无独立评点；若范围增大需与骨肿瘤方向鉴别（骨纤/非骨化性纤维瘤谱系）
4. **对照链三要素再验证**：2023超声（5.0×3.5×1.1cm）与2026 MRI（33×7×53mm）跨模态不可直接对照——**超声与MRI测量口径互斥**，对照链仅在2025-04 vs 2026-04两次MRI间成立（"较前略大"判定有效）；与10-30王某婷案DR/CT分辨率断裂同构，扩展为"跨模态对照断裂"第2例
5. 已愈3年的一过性髋滑膜炎：无独立评点（儿童自限性疾病痊愈路径，与赵某案先髋术后痊愈同构）
