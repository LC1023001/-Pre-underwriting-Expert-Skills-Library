# 个案沉淀：42岁女性双3类结节组合（C-TIRADS 3 + BI-RADS 3）+ 脂肪肝 + 偶发早搏 + 胆囊/巧囊术后 + 咽后壁赘生物待排（2026-10-15评估）

- 被评估人：女，42岁，BMI 22.8，血压96/65
- 资料来源：瑞慈体检2026-05-10（含2016/2017历史）+ 美羡体检2024-10-27（含2023对照）

## 本案新观察（知识库基线未覆盖）

1. **双3类结节组合（C-TIRADS 3 + BI-RADS 3，均未手术）**：基线05矩阵仅有单项条目（C级线索）。本案观察：甲状腺结节10年稳定（2016→2026，最大14×7mm等回声）+乳腺结节2年稳定且缩小（4×5→4×2mm）→ 主路线"除外甲状腺+乳腺"（重疾/医疗），两项除外在器官波及原则（LIA B级）下可控；长期稳定+未升级分级的证据链是复议争取方向。**待多案验证**：双3类结节是否在部分宽松主体可争取单项除外或标准体。
2. **咽后壁赘生物"待排"（未闭环未定性体征）**：知识库检索0命中。本案定位为唯一延期风险点——严格主体可能就这一单项要求延期至耳鼻喉专科明确。与既往"肺影未查CT"案（2026-10-14）规则一致：**体检报告"待排/建议进一步检查"项未闭环 = 高风险不确定性**。
3. **偶发早搏跨年观察（2024 ECG偶发室性期前收缩 → 2026 ECG正常、仅触诊早搏2次/分）**：知识库无具名条目。无甲亢/无贫血/无器质证据的功能性早搏，寿险大概率标准体；严格主体或要求Holter。**待多案验证**。
4. **胆囊结石切除术后4年（胆总管6mm正常、肝功正常）**：与2026-10-09肺磨玻璃结节案（胆囊切除+ERCP术后<6个月延期观察）形成对照——**术后年限是胆道核保的关键分界**：4年+无并发症 → 重疾/寿险标准体、医疗多不额外除外（本案观察，待验证）。
5. **卵巢巧克力囊肿剥除术后2年（无复发征象、CA125正常）**：知识库0命中。良性病理+无复发 → 争取妇科不除外；TCT NILM+HPV16/18阴性形成宫颈风险闭环证据链。

## 室早波形专项分析（2026-10-15 追加）

**方法**：从体检PDF提取心电图原图（2026年12导联+II长节律条、2024年12导联+解析），高倍放大逐波判读 + 节律条程序化R-R间期测距（列暗度峰值检测）。

**发现**：
1. **2024 ECG**（机器判读"偶发室性期前收缩"）：打印窗口内12导联QRS均一狭窄、均见窦性P波，**未见典型室早波形**（提前+宽大畸形>120ms+无P+代偿间歇四要件均缺）→ 室早发生于打印窗口外的分析时段，负荷极低；aVL个别搏动电压略高判为呼吸性变异（同步导联无对应畸形波）。
2. **2026 ECG**（结论正常）：II长节律条程序化测距**12搏R-R间期165–179px、变异<5%、完全规则**，未捕捉早搏；但听诊"早搏2次/分"——听诊早搏呈一过性、静息采样窗口未捕获。
3. **跨年定性**：QRS 84ms两年不变、QTc正常、无ST-T改变、无病理性Q波、电压正常（RV5+SV1：1.905/1.459mV）→ **无器质性心脏病证据**；TSH 1.40排除甲亢、Hb 142排除贫血 → **偶发性功能性早搏可能性大，两年无加重**。

**核保应用**：
- 寿险大概率标准体；重疾/医疗不因该单项加费/除外（按LIA器官波及原则推导）
- 机器判读"室性期前收缩"字样触发告知问项→自动化引擎边界案件退人工；**两年ECG对照+参数全正常=争取标准体的举证材料**
- 主动举证策略：先行24h Holter（预期负荷<1%、单形性），变被动为主动
- 常规12导联对偶发早搏灵敏度低（采样仅数秒~十数秒）——**单次ECG"正常"不能否定听诊早搏，Holter为负荷定量金标准**（方法学要点）

**可复用方法沉淀**：PDF报告心电图图像提取→波段裁切放大→R-R间期程序化测距→波形四要件判读→跨年对照定性，已固化为LR-05分析方法论。
