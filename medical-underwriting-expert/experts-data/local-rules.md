# 个人沉淀区规则（local-rules）——升级不覆盖

> 本文件是专家包只读基线之外的**规则增量层**，优先级高于包内基线中的冲突条目。

## 规则 LR-01：引用来源准入门槛（2026-10-10 修订，用户指令）

**触发背景**：用户指出核保评估引用新闻类/软文类文献不可取——出处不明、易被信息灌注失真经验。原规则允许 C 级（行业媒体/经纪平台）作为"参考"级依据，现予废止。

**规则内容**：

1. **核保结论的直接依据仅限 A/B 级**：
   - A 权威：监管文件原文（金融监管总局/原银保监会）、国标（GB/T）、《保险法》等法律原文
   - B 可靠：中国保险行业协会、中国精算师协会、LIA（新加坡人寿保险协会）等国际专业组织、再保险公司核保手册（Munich Re / Swiss Re / SCOR）、权威核保教材
2. **C 级（行业媒体/新闻稿/经纪平台/软文）与 D 级一律降级为"线索层"**：
   - 仅可作检索线索与方向提示，**不得作为核保判断依据**
   - 严禁引用 C/D 级来源的数值、阈值、档位、结论范围支撑判断
   - 仅有 C/D 级支撑时，结论标注 **"实务线索，需人工核保确认"**，不给具名数值
3. **C 级多源互证不升级**：媒体互转常为同一信息源灌注（伪多源），≥2 个"独立"来源不构成升级为依据的条件——此条覆盖原"入库门槛：C 级需 ≥2 个独立来源互证"规则
4. **报告溯源表分层**：依据表只列 A/B 级条目；C/D 级线索单独成节，标题固定为"实务线索（需人工核保确认）"

**效力**：本条已同步写入专家定义文件「引用铁律」「注意事项」，即使包升级覆盖定义文件，本沉淀区条目仍生效。

## 规则 LR-04：评估报告输出维度规范（2026-10-13，用户纠错触发）

**问题**：预核保结论表中曾出现「智能核保」与重疾险/医疗险/意外险并列为一行的错误——「智能核保」是**核保渠道与方式**，不是险种，两者不属同一分类维度，禁止在任何"按险种列举"的表格、清单、摘要中并列混排。

**规范**：
1. **险种维度**（按产品类型）：重疾险、医疗险、防癌险、寿险、意外险、年金险等；
2. **渠道与方式维度**（按承保通道）：智能核保、人工核保、预核保、再保咨询等；
3. 两维度在报告中**分区呈现**：险种维度进入「核保结论」表；渠道维度进入「投保策略建议」章节；
4. 若需交叉说明（如"重疾险经智能核保大概率拦截"），在策略章节以文字表述，不进入险种结论表。

**性质**：输出规范类修正（非数值规则），由用户对 UW-20261013-ZJX 案报告的纠错触发，属个案沉淀回路（回路1）入库。

## 规则 LR-05：心电图波形核保分析方法论（2026-10-15，UW-20261015-XZ案触发）

**性质**：方法论框架（非数值规则），个案沉淀回路（回路1）入库。为"早搏/心律失常"类无具名A/B级档位的病种提供可复用的证据链构建方法。

**方法五步**（可复用）：
1. **图像提取**：从体检PDF提取心电图原图（pymupdf），按版式定位节律条与12导联窗口；
2. **波段放大**：导联行裁切+2~3倍放大，逐波判读P-QRS-T形态；
3. **R-R程序化测距**：节律条波段做列暗度峰值检测（QRS尖峰高度阈值过滤网格噪声），输出R-R间期序列与变异度——变异<5%即规则；
4. **波形四要件判读**：室早=①提前出现②QRS宽大畸形(>120ms)③其前无相关P波、T波与主波相反④后继完全代偿间歇——四要件齐备方可定性；
5. **跨年对照定性**：机器参数对照（PR/QRS/QTc/电压/电轴）+驱动因素排查（甲功/贫血/电解质）+两年趋势。

**定性推理要点**：
- 机器判读"偶发室早"+打印窗口未见波形 → 室早发生于窗口外分析时段，负荷极低（不矛盾，机器分析时段>打印窗口）；
- 听诊闻及早搏但静息ECG未捕捉 → 一过性低频（单次ECG采样数秒~十数秒，灵敏度低，**不能据此否定早搏存在**）；
- 无器质性证据（QRS时限不变、无ST-T改变、无病理性Q、电压正常）+ 驱动因素阴性 → 功能性早搏定性；
- 核保应用：寿险大概率标准体；机器判读字样触发告知问项属自动化引擎边界案件（退人工），两年ECG对照+参数正常为标准体举证材料；可建议先行Holter主动举证（负荷<1%、单形性=良性预期）。

**边界**：本条为方法框架，不改变任何具名核保档位；早搏具名A/B级档位仍属知识库缺口（2026-10-15已登记），待权威来源补强。

## 规则 LR-06：瑞再最新高血压评点方法学（CMC，截至 2026-10）

**性质**：B 级方法学条目（再保公司官方出版物），由 2026-10-20"以瑞再最新高血压评点评估重疾险"任务触发入库。

**来源**：Swiss Re《Cardiometabolic Calculator》官方产品手册（swissre.com/dam/jcr:758f6ef6…/life-guide-cmc-broschurex.pdf）+ Swiss Re《Life Guide 2025 – What's coming up》年度更新概要（swissre.com）｜ B 级 ｜ 截至 2026-10

**瑞再现行高血压评点载体**：Life Guide（NMG 评行业第一核保手册，800+ 公司使用）内的**心血管代谢计算器 CMC**（替代旧版 CVS）。

**方法学要点（可作评估依据的 B 级内容）**：
1. 废弃以 **+25 e.m. 为增量**的阶梯式评点 → **连续平滑风险曲线**，逐岁评估（打破年龄带）
2. **收缩压与舒张压独立建模**，两者对风险的影响不同且随年龄变化；覆盖单纯收缩期/舒张期高血压
3. 风险因素间**乘法交互**建模（如 BMI↔血压、血脂↔血糖），非简单相加
4. **重疾险与失能险评点已随 CMC 更新**，反映死亡率与发病率（morbidity）风险的动态差异
5. 新增/扩展因素：腰围（补强 BMI）、载脂蛋白、肝功能（嵌入 CMC）、CAC 冠脉钙化评分、HRV、hsCRP

**边界（重要）**：高血压**具名 EM 档位数值**（各血压水平对应 e.m. 值）在 Life Guide 付费墙内，公开渠道无 A/B 级数值表——个案评估只可按上述方法学做方向性推导，具名数值结论一律标注"需人工核保确认"。

**应用框架**：高血压重疾险评估按 CMC 输入变量结构化收集：①收缩压/舒张压实测值（分列）②年龄/性别 ③BMI+腰围 ④血脂（含 Apo 如有）⑤血糖代谢 ⑥治疗与控制情况 ⑦靶器官损害 ⑧共病；结论按连续风险曲线思路给区间方向，不做档位换算。

## 规则 LR-07：瑞再 GLP-1 减重药物核保要点（B 级，截至 2026-10）

**性质**：B 级方法学条目（再保公司官方出版物），由 2026-10-20"BMI 40→36.9 减肥后评估"任务触发入库。知识库此前对"减重/减重药物"零覆盖。

**来源**：Swiss Re《From hype to evidence: What real-world GLP-1 data means for insurers》（2026-04-16，swissre.com/reinsurance/insights/what-glp-1-data-means-for-insurers.html，基于 Milliman IntelliScript Irix® 2020-2025 美国投保人群处方+医保理赔数据）｜ B 级

**要点（可作评估依据）**：
1. GLP-1 使用者基线死亡风险评分均值 **1.48（对照普通人群 1.0）**——常伴心血管代谢共病（心血管病、高血压、高胆固醇）
2. **减重适应证使用者**的死亡风险评分**低于糖尿病使用者**
3. **依从性（MPR）与模型死亡风险负相关；治疗时长本身不独立降低风险**——依从性、基础疾病负荷、行为参与比暴露时长更重要
4. 长期健康结局取决于**持续、成功的生活方式改变**（停药维持问题官方未给出定量结论）
5. 2025 年美国投保人群中近 1/3 GLP-1 使用者无糖尿病处方码（减重用途占比逐年上升）

**核保应用**：GLP-1 减重个案按"**当前 BMI+腰围（LR-06 CMC）+ 心血管代谢共病 + 用药依从性**"四要素评估；用药本身不构成加分或扣分项；已停药者需体重维持记录佐证"新常态"。具名评点数值仍在 Life Guide 付费墙内。

**关联线索（C 级）**：媒体转述瑞再观点——停药后体重反弹为行业公认的建模难题（insurancebusinessmag，C）；美国经纪平台"12 个月体重稳定规则"（pennypincher，C）——均仅作方向线索。

## 规则 LR-08：时间节点 × 资料齐全度双维评估与照会/复查输出规范（2026-10-21，用户指令触发）

**性质**：方法论与输出规范（非数值规则），回路1入库。由用户对 UW-20261021-QDD 案报告的肯定触发：「根据时间节点和资料齐全程度给出建议照会和复查的要求是一大进步」；**同日二次修订**（用户指令）：照会/复查为条件触发而非每案必备——资料完备、无诊疗逻辑空白时直接出结论，不强制要求复查。

**双维评估法**（凡非标体案件，评点前必须先过双维定位）：

| | 资料齐全（证据链闭环） | 资料缺失（证据链断裂） |
|---|---|---|
| **时间窗口内**（事件锚点距今未满常见观察窗） | 延期——附**复查时间表**（复查什么、何时、预计可投保时点） | 延期为主——同时**预告将来照会清单**（一次告知，避免客户反复跑） |
| **时间窗口外/临界** | 进入正式评点（标准体/加费/除外） | 照会——附**材料清单**（缺什么、去哪查、为什么需要） |

- **维度A·时间节点**：以关键医学事件为锚点（发作/确诊/手术/治疗起始/指标复常），计算距投保时点的经过时间，对照常见观察窗判断阶段。**"何时发生的"与"现在是否正常"同等重要**——单次复常不等于窗口已过。
- **维度B·资料齐全度**：证据链三要素逐一核对——①**定性证据**（病因/病理/分型，如 HBV-DNA、息肉病理、EEG）②**控制证据**（连续复查指标，单次正常不闭环）③**器官状态证据**（影像/功能，如超声、Holter、肠镜）。
- **延期与照会的区分**（本案方法论核心）：时间缺口→复查时间表；材料缺口→照会清单。两者都是**可执行的下一步**而非笼统的"建议复查"。

**输出规范（2026-10-21 同日修订：条件触发，非每案必备）**：
1. **默认路径（免照会/免复查）**：资料完备度高——证据链三要素齐备（定性/控制/器官状态）、处时间窗口外、无显著诊疗逻辑空白或瑕疵——**直接给出核保结论，不附照会清单、不要求复查**。既有资料已能支撑准确结论时，"为查而查"的复查无核保增益，反而拖累时效、损害客户体验。
2. **条件触发**：双维定位落在缺口象限时，才生成对应模块——
   - 时间缺口 → **复查时间表**（事件锚点 → 观察窗 → 预计可投保时点 → 届时需携带的复查证据）；
   - 材料缺口 → **照会清单**（逐项列检查/材料 + 核保目的 + 建议时机）；
   - 复合缺口 → 两模块并列，一次性完整告知（避免客户反复跑）。
3. **"无空白"判定的从谨慎则**：以下情形属**隐性缺口**，不得按资料完备处理，仍须照会或复查——临界值指标（刚过阈值/刚好达标）、单次检查定性（无跨期对照）、疑问表述诊断（"待排/?/疑诊"）、关键驱动因素未查（如心律失常未查甲功）、结论对单一指标高度敏感而该指标仅测一次。

**个案观察窗汇总（D 级个案观察，待多案验证，不得作为具名依据输出）**：
- 肝炎活动期肝功复常：~6 个月（10-21 钱某案）
- 结肠腺瘤切除后肠镜复查阴性：6-12 个月（10-20 LXY案）
- NEC 保守治愈：12 个月（10-14 女童案）
- GBS 发病后神经传导复查：≥1 年（10-14 案）
- RA 规范治疗稳定：6-12 个月（10-13 案）
- 胆囊切除术后：<6 个月与 4 年+为关键分界（10-15 案观察）
- 儿童惊厥无复发：满 2 年 + 年龄>5 岁为有利窗口（10-21 女童案）

**边界**：本条为方法框架，不改变任何具名核保档位；上表观察窗数值均为个案累积，具名结论一律标注"实务线索，需人工核保确认"。
