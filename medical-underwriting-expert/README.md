# 人身险医学核保评估专家（Medical Underwriting Assessment Expert）

20 年人身险医学核保评估经验的 AI 专家：内置**重疾险核保评估引擎**（1000+ 疾病规则、36 组共病组合、NRS 数字评点、250+ 再保规则、5000+ 评点）与**可溯源知识库**（监管规范、再保评点方法学、人身险核保规则、非标体矩阵），并提供国际再保险核保方法学视角（死亡指数 TM、额外死亡率 EM、次标准体三种承保方式、慕再 MIRA/NRS 评点体系、财务核保与职业风险）。**所有结论强制附「来源｜日期｜可信度」三元组，判断依据仅限 A/B 级权威来源。**

## 类型

Agent 型（单个 AI 专家）　｜　`categoryId: 12-IndustryConsultant`　｜　版本 `1.6.3`

| 能力 | 说明 |
|------|------|

| 带病体/非标体评估 | 基于病种分类 × 36 组共病组合 × 9 种中医体质，评估可投保范围与拒保边界 |
| 人身险医学核保 | 死亡指数 TM 与额外死亡率 EM 分层结论；次标准体三种承保方式、财务核保、职业与居住地风险、老年核保、高保额常规核保 |

## 规则沉淀闭环

```
单案沉淀 ──┐
规则吸收 ──┼──▶ 判定权威序(A>B>C>D) ──▶ 分级入库 / 冲突修正 ──▶ 版本号递增
冲突修正 ──┘
```

四条回路：单案沉淀、规则更新吸收、冲突修正、自身进化。**红线**：单次个案只做沉淀；仅 A/B 级权威来源可触发对规则表的修改。

### 如何让它真正跑起来

| 回路 | 触发方式 | 说明 |
|------|---------|------|
| 单案沉淀 | 自动 | 每次评估后自动判断是否有可沉淀增量 |
| 冲突修正 | 自动 | 发现既有规则与权威来源不符时立即修正 |
| **规则更新吸收** | **需你触发** | 说「**更新核保知识库**」——⚠️ **不会自动联网更新** |
| 自身进化 | 自动（有门槛） | 仅 A/B 级来源可触发 |

**关于「定时更新」**：定时任务不随专家包分发，需要你自己在 WorkBuddy 里建一个自动化任务（例如每周一 09:00 执行「更新核保知识库」），即可获得与官方源同步的持续演进。

### 你的沉淀存在哪里

| 位置 | 性质 | 专家包升级后 |
|------|------|:-----------:|
| 包内 `skills/uw-knowledge-base/`、`skills/ci-underwriting/` | 出厂基线（只读） | 被新版本替换 |
| `~/.workbuddy/experts-data/health-underwriting-expert/` | **你的个人沉淀区** | ✅ **保留，不覆盖** |

> 个案沉淀、新增规则、更新日志一律写入**个人沉淀区**——这是你自己的知识资产，不会因为插件升级而丢失。

## 边界声明

- 输出为 AI 辅助参考意见，**不构成正式核保结论，亦不构成保险产品推荐或投保建议**
- 实际承保结果以保险公司正式核保决定为准
- 涉及具体产品、费率、承保条件的最终决策，请咨询持牌保险从业人员
- 知识库只做方法学归纳与要点提炼，不转载受版权保护的资料原文
- **不收录各机构专有核保细则与限额数值表**；引用机构规则时标明为"某机构口径"，并提示以承保机构现行规程为准
- 慕再 EM、瑞士再 Table、Gen Re 评分为**三套独立体系**，只可并列引用，严禁互相换算或混算
