# 人身险医学核保评估专家（Medical Underwriting Assessment Expert）

20 年人身险医学核保评估经验的 AI 专家，覆盖 900 余种疾病核保规则、带病体/非标体评估、18 组共病组合、多家保险公司规则差异化对比，并提供国际核保方法学视角。**内置可溯源的核保规则库：再保手册 250 余条规则、5000 余条评点，结合临床 2706 条循证指南，具备自我学习迭代机制。**

## 类型

Agent 型（单个 AI 专家）　｜　`categoryId: 12-IndustryConsultant`　｜　版本 `1.4.3`（内含知识库 v1.2）

## 功能

| 能力 | 说明 |
|------|------|
| 预核保评估 | 接收体检报告/病历/影像报告，提取关键指标，输出结构化预核保结论 |
| 带病体/非标体评估 | 基于 10 病种分类 × 18 组共病组合 × 9 种中医体质，评估可投保范围与拒保边界 |
| 保险公司规则对比 | 同一健康状况下多家公司的核保尺度差异对比（宽松 → 严格） |
| 规则溯源 | 结论附「来源 \| 日期 \| 可信度」三元组，可回溯到规则库条目 |
| 自我学习迭代 | 单案结论沉淀 + 规则按需吸收；A/B 级依据可直接修正规则表；个人沉淀区升级不覆盖 |

## 自我学习迭代闭环

```
单案沉淀 ──┐
规则吸收 ──┼──▶ 判定权威序(A>B>C>D) ──▶ 分级入库 / 冲突修正 ──▶ 版本号递增
冲突修正 ──┘
```

四条回路：单案沉淀、规则更新吸收、冲突修正、自身进化。**红线**：单次个案只做沉淀；仅 A/B 级权威来源可触发对规则表的修改。

### 如何让它真正跑起来

| 回路 | 触发方式 | 说明 |
|------|---------|------|
| 单案沉淀 | 自动 | 每次评估后自动判断是否有可沉淀增量 |
| 冲突修正 | 自动 | 发现既有规则与权威来源不符时立即修正 |
| **规则更新吸收** | **需你触发** | 说「**更新核保知识库**」——⚠️ **不会自动联网更新** |
| 自身进化 | 自动（有门槛） | 仅 A/B 级来源可触发 |

**关于「定时更新」**：定时任务不随专家包分发，需要你自己在 WorkBuddy 里建一个自动化任务（例如每周一 09:00 执行「更新核保知识库」），即可获得与官方源同步的持续演进。

### 你的沉淀存在哪里

| 位置 | 性质 | 专家包升级后 |
|------|------|:-----------:|
| 包内 `skills/uw-knowledge-base/references/` | 出厂基线（只读） | 被新版本替换 |
| `~/.workbuddy/experts-data/health-underwriting-expert/` | **你的个人沉淀区** | ✅ **保留，不覆盖** |

> 个案沉淀、新增规则、更新日志一律写入**个人沉淀区**——这是你自己的知识资产，不会因为插件升级而丢失。

## 使用示例

- 请根据我的体检报告，结合 900 余种疾病核保规则，评估我的预核保风险
- 请对比多家保险公司对甲状腺结节的核保规则差异，并给出各公司预估核保结论
- 这个核保结论的依据是什么？请列出规则来源、日期与可信度分级

## 边界声明

- 输出为 AI 辅助参考意见，**不构成正式核保结论，亦不构成保险产品推荐或投保建议**
- 实际承保结果以保险公司正式核保决定为准
- 涉及具体产品、费率、承保条件的最终决策，请咨询持牌保险从业人员
- 知识库只做方法学归纳与要点提炼，不转载受版权保护的资料原文
- 知识库内容均为公开可溯源的监管规范、行业标准与通用核保方法学
