# 药物相关问题（DRP）分类与识别指南

## DRP 分类体系（参照 PCNE 分类系统 V9.1）

### 一、治疗效果问题（P1）
| 编码 | 描述 | 常见原因 | 慢病示例 |
|------|------|---------|---------|
| P1.1 | 治疗效果不佳 | 剂量不足、依从性差、药物选择不当 | 高血压未达标、血糖控制差 |
| P1.2 | 治疗效果过强（毒性/不良反应） | 剂量过高、相互作用 | 华法林出血、低血糖 |
| P1.3 | 不必要的治疗 | 无适应症用药、重复用药 | 多种同类降脂药 |
| P1.4 | 未治疗的适应症 | 漏诊、医患沟通不畅 | 心衰未加用 SGLT2i |

### 二、安全性问题（P2）
| 编码 | 描述 | 重点监测药物 |
|------|------|------------|
| P2.1 | 不良药物反应（ADR）— 非剂量相关 | 过敏反应、ACEI干咳、他汀肌病 |
| P2.2 | 不良药物反应（ADR）— 剂量相关 | 二甲双胍乳酸酸中毒（eGFR<30时）|
| P2.3 | 药物中毒 | 地高辛中毒、华法林过量 |
| P2.4 | 潜在不良反应风险 | 老年人使用苯二氮䓬类 |

### 三、治疗依从性问题（P3）
| 编码 | 描述 | 评估工具 |
|------|------|---------|
| P3.1 | 患者主动不依从（拒绝用药） | Morisky-8问卷 |
| P3.2 | 患者无意识不依从（忘记服药） | 药片计数法 |
| P3.3 | 患者不当使用药物 | 吸入装置技术评估 |

## 常见药物相互作用（DDI）快速参考

### 高血压用药 DDI
| 药物组合 | 相互作用 | 处理建议 |
|---------|---------|---------|
| ACEI + 保钾利尿剂/螺内酯 | 高钾血症风险↑ | 监测血钾，尤其CKD患者 |
| ACEI + ARB | 高钾、肾损伤风险↑，获益不增 | 避免联合使用 |
| β受体阻滞剂 + 维拉帕米/地尔硫䓬 | 心动过缓、房室传导阻滞 | 禁止联合，HFrEF尤其危险 |
| NSAIDs + 降压药（各类） | 血压升高，拮抗降压效果 | 避免长期使用NSAIDs |

### 糖尿病用药 DDI
| 药物组合 | 相互作用 | 处理建议 |
|---------|---------|---------|
| 磺脲类 + 氟喹诺酮类 | 严重低血糖风险 | 监测血糖，必要时调整剂量 |
| 二甲双胍 + 碘造影剂 | 乳酸酸中毒风险 | 造影前48h停药，造影后48h复查肾功能后恢复 |
| SGLT2i + 利尿剂 | 脱水、低血压风险 | 监测血压和容量状态 |
| 胰岛素 + β受体阻滞剂 | 掩盖低血糖症状（心悸消失，出汗保留） | 糖尿病患者教育出汗作为低血糖信号 |

### 心血管用药 DDI
| 药物组合 | 相互作用 | 处理建议 |
|---------|---------|---------|
| 华法林 + 阿司匹林 | 出血风险显著↑ | 除特殊适应症外避免联合 |
| 他汀 + 胺碘酮 | 他汀血药浓度↑，肌病风险 | 他汀减量（辛伐他汀≤20mg） |
| 他汀 + 大环内酯类/唑类抗真菌 | CYP3A4抑制，他汀浓度↑ | 短期使用抗生素时暂停他汀 |
| 地高辛 + 胺碘酮 | 地高辛浓度升高50-100% | 减少地高辛剂量，监测血药浓度 |
| NOAC + 强P-gp抑制剂 | NOAC浓度升高，出血风险 | 如伊曲康唑——避免联用 |

## Beers 标准（老年人潜在不适当用药，2023版精要）

### 应避免使用（任何情况）
- 一代抗组胺药（苯海拉明、氯苯那敏）— 抗胆碱能，谵妄风险
- 肌松药（安定类）— 跌倒风险
- 苯二氮䓬类（长期使用）— 认知损害、跌倒
- 非苯二氮䓬类催眠药（唑吡坦）— 跌倒、骨折
- 雄激素（常规补充）— 心血管风险
- 多数磺脲类（格列本脲）— 持续低血糖风险
- PPIs（长期，>8周无适应症）— 艰难梭菌、骨折、低镁

### 慎用（特定情况）
- NSAIDs：避免常规用于 ≥75岁，除非无其他替代且同时使用PPI
- 三环类抗抑郁药：低血压、心律失常风险
- 抗精神病药：非痴呆相关精神行为症状时避免
- 地高辛 >0.125mg/d：毒性风险增加

## STOPP/START 标准精要（老年多病共病适用）

### STOPP（应考虑停用的药物）
1. 无明确指征的 PPI（继续使用率极高）
2. 无症状的哮喘/COPD 患者继续使用高剂量 ICS
3. CKD G4-G5 患者使用 NSAIDs
4. 已出现跌倒史的老年人继续使用苯二氮䓬类
5. 无 ASCVD 史的 >85岁老年人使用强他汀（收益有限）

### START（应考虑启动的药物）
1. 已确诊冠心病但未使用阿司匹林
2. 心衰（HFrEF）患者未使用 ACEI/ARB
3. CKD 合并蛋白尿未使用 ACEI/ARB
4. ≥65岁骨质疏松未使用维生素D+钙剂
5. T2DM 合并 ASCVD 未使用 GLP-1RA 或 SGLT2i
